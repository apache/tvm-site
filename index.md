#### Projects

    *  **[TVM TIRx](https://github.com/apache/tvm-tirx/)**: the ML compiler foundation. A minimal,
       stable core IR with an open operator system, utilities for symbolic analysis, structural
       traversal and mapping, and code generation for CUDA and host LLVM targets.
    *  **[TVM FFI](https://github.com/apache/tvm-ffi/)**: an open ABI and FFI for ML systems. It
       lets compiler objects, functions, and tensors move across Python, C++, Rust, and
       frameworks such as PyTorch.
