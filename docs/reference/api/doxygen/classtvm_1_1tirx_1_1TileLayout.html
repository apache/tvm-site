◆ IsContiguous()

TVM_TIRX_DLL bool tvm::tirx::TileLayout::IsContiguous ( ffi::Optional< sym::Analyzer >  analyzer = std::nullopt) const

Whether the tile describes contiguous row-major memory strides.

Memory-axis origins do not affect this predicate. Replicas and non-memory axes are rejected; unit extents may have arbitrary strides. Deep equality is tried first, reusing the supplied analyzer or lazily creating one for proof.
