Detailed Description

template<typename Derived>
class tvm::Pattern< Derived >

Base class of all the patterns.

There are two major member functions supported by each pattern.

  • Match: checks if value matches the pattern.
  • Eval: construct a new value based on matched values in PVar.

We use curiously recurring template pattern to construct expression templates.

Nested storage type in the expression.

Depending on the Derived class, Nested can be Derived (nest by value) or const Derived& (nest by reference).

The trick of Nested typedef originates from Eigen.

Note
We use nest by value for intermediate expressions, and nest by reference for PVars.
