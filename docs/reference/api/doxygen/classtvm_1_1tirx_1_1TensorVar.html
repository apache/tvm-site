Detailed Description

Checked zero-state view over an ordinary VarNode with TensorType.

TensorVar does not introduce a runtime object or a second identity. It safely widens to Var, and get() returns the underlying VarNode used by identity-sensitive maps. operator-> exposes the immutable TensorType access contract for concise compiler-side metadata access.
