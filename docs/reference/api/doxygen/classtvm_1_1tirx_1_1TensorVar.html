Detailed Description

Checked zero-state view over an ordinary VarObj with TensorType.

TensorVar does not introduce a runtime object or a second identity. It safely widens to Var, and get() returns the underlying VarObj used by identity-sensitive maps. operator-> exposes the same VarObj, while ty() and the metadata accessors expose its immutable TensorType access contract.
