Transform the high-level Function to a low-level version that can be used as an API function.

The main task of this function is to create code to :

  • Map the values in the api_args to Var that is required by body.

◆ SplitHostDevice()

TVM_TIRX_DLL Pass tvm::tirx::transform::SplitHostDevice ( )

Annotate, split, and lower host/device functions.

This pass first annotates device regions within host functions, then splits them into host and device-side Functions, and finally lowers host-to-device calls into the device kernel launch ABI.

The resulting host-side function will keep the same tvm::attr::kTarget attribute (e.g. T.target("cuda", host=T.target("llvm"))). This ensures that MakePackedAPI knows which device type should be used for the input tensors.

The resulting device-side function will have the host stripped from its target attribute (e.g. T.target("cuda")).

Returns
The pass.
