Detailed Description

Native visiting with exact dispatch and structural fallback.

Allocate visitors with ffi::make_object<Derived>(). Inputs are borrowed; interrupts and errors own their values. A hook controls descent into its node. One visitor must not be shared by overlapping traversals.
