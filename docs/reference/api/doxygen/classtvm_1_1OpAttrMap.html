Detailed Description

template<typename ValueType>
class tvm::OpAttrMap< ValueType >

Typed live view of an Op attribute column.

Copies share the retained mutable column and observe later registrations, replacements, resets, and growth. Values are returned by value, never as references into a backing array. Registration is not synchronized with readers.
