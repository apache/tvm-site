Check if value matches one of the patterns.

This call also populates the PVars with matched value based on the first successful match. The values in PVars are valid until the next call to Match.

Parameters
valueThe value to be matched against.
condA callable that performs additional validation, returning true if the match passes. This will typically be a lambda function written in terms of the filled PVars. This will be called once for each successful pattern match. If cond() returns false, the next match will be attempted.
Returns
Whether value matches the pattern.
