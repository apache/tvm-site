Detailed Description

Standalone statement that declares a scope-id binding (e.g. cta_id, warp_id, lane_id). Carries a ScopeIdDef value.

Each declaration is a flat stmt within the device-region body. The declared Var\ s are visible in subsequent stmts in the same enclosing scope (the tirx.device_entry region body), analogous to BindNode.
