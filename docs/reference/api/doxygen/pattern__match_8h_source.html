288 // Hold the patterns by const&. This follows the same usage as both
289 // the `PVar`, which occurs as `const PVar<T>&` when it appears
290 // inside other patterns. Because the `PVar<T>::value_` field is
291 // mutable, it can still be updated through these const references.
292 // So long as the call to `Match()` occurs within the same
293 // expression as created the patterns, this avoids accidental copies
294 // without creating dangling references. This may be improved in
295 // the future by use of `constexpr` constructors/operators, allowing
296 // more typical value semantics.
297 std::tuple<const TPattern&...> patterns_;
298};

300/* \brief Return a proxy object that returns true after the first match
301 *
302 * In the RewriteSimplifier, there are often several expressions that
303 * simplify to the same resulting expression. This utility allows
304 * them to be specified as a single rule, reducing duplication of the
305 * result/condition of a rewrite.
