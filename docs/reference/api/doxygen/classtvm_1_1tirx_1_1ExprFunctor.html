Detailed Description

template<typename FType>
class tvm::tirx::ExprFunctor< FType >

Dialect entry point for shared expression dispatch.

Override Dispatch_ for a node type or DispatchDefault_ for default behavior. Core expression hooks, result types, argument forwarding and registered-ancestor dispatch are inherited from tvm::ExprFunctor. This functor does not recurse automatically. Derived dialect extensions can initialize a fresh inherited table with InitVTable and register additional hooks with SetDispatch.
