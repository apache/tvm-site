static Type tvm::Call::ReinferType ( const CallNode *  call)
static

Recompute a result type from the Call's current explicit inputs.

This ignores the Call's stored result type and does not mutate the Call. Returns Missing when no deduction is available; inference errors propagate. This does not invoke the operator's validator.
