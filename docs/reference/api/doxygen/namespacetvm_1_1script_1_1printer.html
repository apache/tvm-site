using tvm::script::printer::FDocTranslate = typedef ffi::reflection::NativeFunctionView<ffi::Optional<ExprDoc>( DocTranslatorObj* translator, ffi::AnyView value, const ffi::Object* destination)>

Native translation hook with borrowed inputs and an owning result.

Parameters
translatorTranslation context borrowed for the duration of the call.
valueInput value borrowed for the duration of the call.
destinationOptional binding variable borrowed for the duration of the call.
Returns
An owning expression Doc, or None after completing emission. Return an expression for the caller to consume, or None after completing emission and any requested binding. Packed hooks use the same contract and None for a null destination; native errors cross the ABI through Expected.
