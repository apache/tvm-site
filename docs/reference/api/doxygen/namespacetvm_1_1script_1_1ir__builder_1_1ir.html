Append a statement to the current statement frame or top-level builder result.

Parameters
stmtThe statement to append, flattening top-level sequences with copy-on-write.
locThe deferred source location, used only when the statement has UnknownLoc. Empty top-level sequences add no statements to an existing result. Existing statement locations and results retained by callers are preserved.
Exceptions
