Detailed Description

Optional Z3-backed prover over the analyzer's accepted premises.

Diagnostic and enumeration queries may propagate translation or solver errors. Their temporary assertions do not change the accepted premise environment.

Count the number of integer values that satisfy the current constraints.

Enumerates distinct values until the limit, unsatisfiability, or an inconclusive result. The count may be partial; it is not a proof of the domain cardinality.

Parameters
varThe variable to count satisfying values for.
max_countMaximum number of values to enumerate; nonpositive values enumerate none.
min_consecutiveMinimum size of each consecutive run in the enumerated values; nonpositive values disable this check. The check does not establish complete coverage.
Returns
The enumerated count, -1 for an unsupported variable or disabled Z3, or -2 if a nonempty enumerated run is shorter than min_consecutive. Errors may propagate.
