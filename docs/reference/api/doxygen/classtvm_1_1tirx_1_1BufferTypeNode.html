Detailed Description

Structural type of a TIRx buffer variable.

A buffer value is an ordinary VarNode whose ExprNode::ty is BufferType. BufferType owns the immutable access contract. The physical pointer is deliberately not stored here; it is obtained with buffer_data(BufferVar) and is bound by the surrounding buffer definition.
