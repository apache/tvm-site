Detailed Description

Construct a vector with lanes elements where its i-th element equals base + i * stride. This is useful to construct an index for a continuous vector load. Base and stride must be scalar int32, int64, uint32, or uint64. The stride is cast to the base type when their types differ. Other element types can be expressed by explicitly casting the resulting vector.

Examples:

  • ramp(0, 1, 3) = [0, 1, 2]
  • ramp(1, 2, 4) = [1, 3, 5, 7]
