Detailed Description

template<typename K, typename V, typename Hash = std::hash<K>, typename KeyEqual = std::equal_to<K>>
class tvm::support::OrderedMap< K, V, Hash, KeyEqual >

An STL-like map that preserves insertion order.

Template Parameters
KThe key type.
VThe value type.
HashThe hash function.
KeyEqualThe key equality function.
Note
we don't support erase since it is less needed and vector backing is more efficient.
