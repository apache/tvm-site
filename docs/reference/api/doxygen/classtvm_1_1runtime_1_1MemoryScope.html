Detailed Description

A registered memory space, independent of backend allocation policy.

Register extensions with ffi::reflection::EnumDef<MemoryScopeObj>("my.scope"). Registration order has no semantic meaning. A backend must explicitly support a scope before it can allocate storage in that space.
