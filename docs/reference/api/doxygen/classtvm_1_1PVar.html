Detailed Description

template<typename T>
class tvm::PVar< T >

Pattern variable container.

PVar is used as a "hole" in the pattern that can be matched.

Template Parameters
Tthe type of the hole.
Note
PVar is not thread safe. Do not use the same PVar in multiple threads.
