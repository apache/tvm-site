Detailed Description

Native object mutation over one constraint-aware engine and variable remap.

Override Mutate for general dispatch. Forward inherited permission to children; the entry point checks uniqueness before dispatching a native hook. Unregistered values use structural fallback. Errors propagate without restoring the context.
