static GPUThreadTag tvm::support::GPUThreadTag::Parse ( const ffi::String &  tag)
inlinestatic

Parse a physical GPU thread tag.

Recognizes blockIdx., threadIdx., clusterCtaIdx., and preferredClusterCtaIdx. prefixes. The first character after the prefix determines the dimension; trailing characters are ignored. Consumers validate supported ranks and dimensions.
