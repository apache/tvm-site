constexpr ffi::reflection::AttrKey< ffi::reflection::NativeFunctionView<ffi::Array<Var>(const CallObj* call)> > tvm::op_attr::kRegionGetBodyParams {"FRegionGetBodyParams"}
inlineconstexpr

Construct fresh typed variables for a region's lexical body parameters.

The input carries only the operation, operands and attributes, without a body or builder state. Parameters are ordered, distinct definitions and may have name hints. Every region operation must register this hook, returning an empty array when it has no body parameters. Presence of the attribute identifies region support without invoking the hook or allocating variables.
