Detailed Description

Extend native TIRX mutation while preserving block iterator binders.

Reuses inherited remapping and ownership checks. Block annotations are left intact; structural mutation separately provides the full field rewrite. Generic TIRX mutators instead use the full structural rewrite, including iterator definitions and annotations. Both paths establish allocation and match-buffer remaps before visiting region uses and preserve copy-on-write.
