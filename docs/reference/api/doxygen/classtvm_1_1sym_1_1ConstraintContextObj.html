Detailed Description

Tracks the constraints relevant to each point in a traversal.

Holds variable bindings, value ranges, and predicates collected during traversal. Callbacks can inspect these constraints when processing the current expression or statement. Captured constraint and expression nodes must not be changed through aliases: appending preserves earlier prefixes, but snapshots do not deep-copy their contents.

ConstraintContext tvm::sym::ConstraintContextObj::Snapshot ( ) const
inline

Captures the constraints currently visible in this context. Later additions to this context do not affect the returned context, which can be extended independently. Constraint objects and referenced expressions remain shared. For an existing integer expression x:

sym::ConstraintContext context;
context->Append(sym::PredicateConstraint(x >= 0));
auto saved = context->Snapshot();
context->Append(sym::PredicateConstraint(x < 16));
// saved contains x >= 0; context contains both predicates.
