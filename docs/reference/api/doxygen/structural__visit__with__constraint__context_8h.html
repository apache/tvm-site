 Walk every occurrence with (value, const sym::ConstraintContext&) callbacks. A trailing TVMFFIDefRegionKind is optional, as in ffi::StructuralWalk. Return Expected<WalkResult>; pre-order Skip prunes descent and Interrupt stops the walk. Post callbacks see a scoped node after its internal scope is restored.
