◆ attrs

ffi::Array<Any> tvm::s_tir::InstructionObj::attrs

The attributes of the instruction. Similar to attributes of an operator, attributes of an instruction are arbitrary constant metadata required by the instructions. For example, the name of the block to be retrieved in GetSBlock.

◆ inputs

ffi::Array<Any> tvm::s_tir::InstructionObj::inputs

The input random variables of the instruction, and the type of each element can be one of the following:

  • SBlockRV
  • LoopRV
  • ExprRV
  • double
  • int64_t
  • String
  • null pointer

ffi::Array<Any> tvm::s_tir::InstructionObj::outputs

  • LoopRV
