Detailed Description

Native object dispatch over one constraint-aware structural visitor.

Override Visit for general dispatch. Derived visitors initialize a native table with InitVTable and SetDispatch; unregistered values use structural fallback. Allocate with ffi::make_object. The inherited constraints handle is the active context.
