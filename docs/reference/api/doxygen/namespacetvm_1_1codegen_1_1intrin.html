Template Parameters
TName mapper with std::string operator()(const PrimType&, std::string). The mapper receives the type and the intrinsic name without its prim. or tirx. prefix. An empty mapped name leaves the original call unchanged.

For example, an off-tree backend can register a C math mapping with OpDef("prim.exp").set_attr<tirx::FLowerIntrinsic>( "my_backend.FLowerIntrinsic", DispatchPureExtern<FloatSuffix>) after including tvm/tirx/op/attr.h.
