Pack imported device libraries into an object file using LLVM.

The generated object can be linked with the host library so that the DSO loader discovers its imported modules. Requires LLVM code generation support.

Parameters
modThe host module with imports.
system_libWhether to expose the packed imports as a system library.
llvm_target_stringFull LLVM target specification, including cross-compilation options.
file_nameOutput path; its extension selects the object format.
c_symbol_prefixOptional blob symbol prefix, valid only for system libraries.
