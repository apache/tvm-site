static

Request a registered IR type's constructor in its script namespace.

Parameters
type_keyThe registered type key.
Note
Call after ObjectDef finalization and all reflection and constructor registration. The first call caches the optional script receiver, including absence for standalone native use. Install the receiver before the first call to enable exposure; errors from an installed receiver propagate.
