Region operations

Operations used by RegionStmt to enclose a lexical body.

Every region operation registers FRegionGetBodyParams, returning fresh typed body parameters or an empty array for no parameters. Attribute presence alone identifies region support; classification does not invoke the hook. Operands and attributes are evaluated outside the body-parameter scope.

Detailed Description

TIRx operator attributes, builtin Ops and expression helpers.

Note
Most of the operator defined here perform simple constant folding when the type is int32 or int64 for simplifying the index expressions.
