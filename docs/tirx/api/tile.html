Tensor Instruction Authoring API#

Use T.cuda.tile or T.trn.tile after from tvm.script import tirx as T. The signatures below list runtime operands first and static keyword qualifiers after *. Tensor variables are expanded to full regions. An omitted unary source defaults to its destination. Named workspace arguments are optional.

See Tensor Instructions for memory, scope, descriptor, and synchronization contracts. These calls produce ordinary IR Calls; the raw scalar instruction namespaces remain T.ptx and T.nki.
