Compiler Transforms#

Transformation passes for lowering and optimizing tensor-level IR.

Pass factories return callable passes: after = PassName()(before), where before is an IRModule. Each pass example includes a complete input module, expected output and invocation.

tvm_tirx.tirx.transform.function_pass(pass_func=None, opt_level: int | None = None, name: str | None = None) → Callable | FunctionPass#

Create a TIRx function pass from a callback or class.

The callback receives (function, module, context) and returns the transformed Function. A decorated class instead implements transform_function(self, function, module, context). With no pass_func, returns a decorator for either form.

Parameters:

  • pass_func (Callable or type, optional) – Transformation callback, or class implementing transform_function.

  • opt_level (int) – Required optimization level for the pass.

  • name (str, optional) – Pass name. Defaults to the callback or class name.

Returns:

result – A pass instance for a callback, a pass class for a class, or a decorator when pass_func is omitted.

Return type:

FunctionPass, type, or Callable

class tvm_tirx.tirx.transform.FunctionPass(pass_info)#

A pass that transforms each tvm_tirx.tirx.Function in a module.

Create instances or subclasses with function_pass(), which supplies pass metadata and adapts a Python callback to the pass manager.

tvm_tirx.tirx.transform.AnnotateEntryFunc()#

Infer and mark an unambiguous TIRx entry function.

Sets tirx.is_entry_func when the module contains only one function and it is TIRx, or when exactly one function is externally exposed and it is a TIRx function.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function(private=True)
    def main():
        pass

@I.ir_module
class Expected:
    @T.function(private=True)
    def main():
        T.func_attr({"tirx.is_entry_func": True})

def run_pass():
    return tr.AnnotateEntryFunc()(Before)

tvm.ir.assert_structural_equal(run_pass(), Expected)

tvm_tirx.tirx.transform.ConvertSSA()#

Give every variable definition in an IRModule a distinct identity.

This pass handles cases where the same tirx.Var appears in multiple functions within the same module. For example, after extracting a fragment from one function into another, where the same tirx.Var may be defined both as within the body of the original function, and as a parameter within the hoisted function.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

The input uses explicit T.Bind statements to reuse a variable and disables the SSA check. Ordinary parsed assignments create distinct variable bindings.

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

v = T.dynamic("v", "int32")

@I.ir_module(check_well_formed=False)
class Before:
    @T.function(private=True)
    def main():
        T.Bind(v, 16)
        T.evaluate(v)
        T.Bind(v, 32)
        T.evaluate(v)

@I.ir_module
class Expected:
    @T.function(private=True)
    def main():
        v = 16
        T.evaluate(v)
        v_1 = 32
        T.evaluate(v_1)

def run_pass():
    return tr.ConvertSSA()(Before)

tvm.ir.assert_structural_equal(run_pass(), Expected)

tvm_tirx.tirx.transform.ForceNarrowIndexToInt32()#

Force index expressions to int32 without range proofs.

Use only when the caller can guarantee representability. Unlike NarrowDataType(), this pass may change overflowing computations. Rejects signed integer tensor parameters and ordinary allocations wider than int32. Explicitly typed local scalars retain their storage type and are cast at narrowed index uses.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Note

This pass should not be used in default cases.

Examples

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function(private=True)
    def main(A: T.Tensor((4,), T.float32)):
        for i in range(T.int64(0), T.int64(4)):
            A[i] = T.float32(1.0)

@I.ir_module
class Expected:
    @T.function(private=True)
    def main(A: T.Tensor((4,), T.float32)):
        for i in range(4):
            A[i] = T.float32(1.0)

def run_pass():
    return tr.ForceNarrowIndexToInt32()(Before)

tvm.ir.assert_structural_equal(run_pass(), Expected)

tvm_tirx.tirx.transform.LowerTVMBuiltin()#

Lower runtime builtins to explicit stack storage and ABI operations.

For example, packed calls gain argument/result slots. Requires the function target attribute for target-dependent lowering.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function(private=True)
    def main():
        T.func_attr({"target": T.target("llvm")})
        T.call_packed("callback", 1)

@I.ir_module

    @T.function(private=True)
    def main():
        T.func_attr({"target": T.target("llvm")})
        stack_ffi_any: T.let[T.Ptr(T.void)] = T.stack_alloca("tvm_ffi_any", 2)
        T.abi_field_set(stack_ffi_any, 0, 13, 1)
        T.abi_field_set(stack_ffi_any, 0, 14, 0)
        T.abi_field_set(stack_ffi_any, 0, 15, T.Cast("int64", 1))
        T.abi_field_set(stack_ffi_any, 1, 13, 0)
        T.abi_field_set(stack_ffi_any, 1, 14, 0)
        T.abi_field_set(stack_ffi_any, 1, 15, T.int64(0))
        T.call_packed_lowered("callback", stack_ffi_any, 0, 1)

def run_pass():
    return tr.LowerTVMBuiltin()(Before)

tvm.ir.assert_structural_equal(run_pass(), Expected)

tvm_tirx.tirx.transform.MakePackedAPI()#

Expose exported functions through the TVM FFI packed-call ABI.

Requires a target attribute with a host target on functions with a global_symbol and the default calling convention. Private functions, functions with other calling conventions, and functions whose target has no host are left unchanged.

Tensor parameter types generate runtime checks for shape, dtype and layout. Symbolic dimensions not defined by other arguments are bound from the incoming DLTensor metadata. For example, a T.Tensor((16, 32), "float32") argument is checked against that shape, while symbolic dimensions are read from the argument’s shape. The resulting function uses the host target and an exported __tvm_ffi_ symbol.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

An exported no-argument function illustrates the packed-call ABI.

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function
    def main():
        T.func_attr({"target": T.target("llvm", host="llvm")})
        T.evaluate(0)

@I.ir_module
class Expected:
    @T.function
    def main(
        self_handle: T.Ptr(T.void),
        args: T.Ptr(T.void),
        num_args: T.int32,
        result: T.Ptr(T.void),
    ) -> T.int32:
        T.func_attr({"global_symbol": "__tvm_ffi_main"})
        T.func_attr({"calling_conv": 1, "target": T.target("llvm")})
        assert num_args == 0, (
            "TypeError",
            ["Expected ", "0", " arguments", " when calling:\n  `", "main()", "`"],
        )
        with T.compute_scope("main_compute_"):
            pass
        return 0

def run_pass():
    return tr.MakePackedAPI()(Before)

tvm.ir.assert_structural_equal(run_pass(), Expected)

Plan storage by moving allocations and reusing compatible storage.

Hoists allocations where valid and shares storage when lifetimes and memory-scope allocation properties permit it.

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

import tvm_tirx as tvm

from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function(private=True)
    def main(output: T.Tensor((2,), "float32")):

            A[i] = T.float32(i)
        output[0] = A[3]
        B = T.alloc_tensor(ty_args=[T.Tensor((4,), "float32")])

        output[0] = A[3]
        A_1 = T.decl_tensor(A.data, ty_args=[T.Tensor((4,), T.float32)])
        for i_1 in range(4):
            A_1[i_1] = T.Cast("float32", i_1 + 1)

import tvm_tirx as tvm

tvm_tirx.tirx.transform.VectorizeLoop(enable_vectorize: bool = True)#

Lower vectorization loops.

Target-dependent vectorization uses the Function’s target attribute, not an ambient target context or nested target attributes. Target-independent fixed-width loops do not require a target. Code needing different vectorization targets must be separated into functions before this pass.

Unsupported loops retain scalar execution. Loops containing assertions always remain scalar. Accessing multiple tensors requires the function’s tirx.noalias attribute unless they are views of the same storage.

Parameters:

enable_vectorize (bool) – Whether vectorization is enabled. Will lower to scalar loop when it is turned off.

Returns:

fpass – The result pass

Return type:

tvm_tirx.ir.transform.Pass

Examples

import tvm_tirx as tvm
from tvm_tirx.script import ir as I, tirx as T
from tvm_tirx.tirx import transform as tr

@I.ir_module
class Before:
    @T.function(private=True)
    def main(A: T.Tensor((4,), T.float32), B: T.Tensor((4,), T.float32)):
        T.func_attr({"tirx.noalias": True})
        for i in T.vectorized(0, 4):
            B[i] = A[i]

@I.ir_module
class Expected:
    @T.function(private=True)
    def main(A: T.Tensor((4,), T.float32), B: T.Tensor((4,), T.float32)):
