Trait IntoWalker 

Source 
pub trait IntoWalker<Marker> { }
Expand description

Conversion into the walker argument of structural_walk.

Accepts a mutable WalkDispatch, a typed callback, a nested callback tuple, or an owned or borrowed WalkWithContextPolicy. Marker distinguishes the supported callback shapes.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
