Trait PackedCallArg

pub trait PackedCallArg {
    type Holder;

    // Required methods
    fn into_packed_arg(self) -> Self::Holder;
    fn as_packed_arg(holder: &Self::Holder) -> AnyView<'_>;
}
Expand description

One argument of a packed call: held for the call, then viewed as an FFI value. &str and &[u8] are held as String and Bytes. Implemented by #[derive(ObjectRef)] and impl_any_compatible_conversions!.
