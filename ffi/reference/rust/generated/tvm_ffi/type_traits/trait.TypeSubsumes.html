Trait TypeSubsumes 

Source 
pub unsafe trait TypeSubsumes<Source: ?Sized> { }
Expand description

Self subsumes Source: every Source value, as stored, is a valid Self, a compile-time fact checked by no code, as C++ type_subsumes_v<Self, Source>. So a container of Source is a container of Self without a copy, as Array::upcast and Map::upcast use.

It holds for every type and itself, and for a base object reference and each derived one, which impl_object_ref_upcast! declares.

§Safety

Every cell that Source strictly accepts, Self strictly accepts, also after a change made through Self.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
