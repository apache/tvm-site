Traits that map Rust types to TVM-FFI values.

Traits§

AnyCompatible
A type whose values an FFI cell can hold: how a value is stored in a TVMFFIAny and read back.
ContainerElement
A value an FFI container such as Array holds: every AnyCompatible type, and Any.
DowncastRefFromAny
A type that Any::downcast_ref and AnyView::downcast_ref borrow from an FFI cell in place, without a reference count change: object types (ArrayObj), managed references (Array<T>, String, any #[derive(ObjectRef)] type), Option of a reference and scalars such as i64.
IntoArg
A T, a &T or a subtype of T, taken where a T is expected; a &str or &[u8] converts into a String or Bytes.
TypeSubsumes
Self subsumes Source: every Source value, as stored, is a valid Self, a compile-time fact checked by no code, as C++ type_subsumes_v<Self, Source>. So a container of Source is a container of Self without a copy, as Array::upcast and Map::upcast use.
