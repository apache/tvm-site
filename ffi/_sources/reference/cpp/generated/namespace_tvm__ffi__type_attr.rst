Namespace tvm::ffi::type_attr
=============================


Type attribute names used by the reflection system. 




.. contents:: Contents
   :local:
   :backlinks: none




Detailed Description
--------------------

Each key names a TypeAttrColumn — a sparse, type-indexed slot that stores a ``Function`` or any other Any-compliant value.



- ``TypeAttrDef<T>.def(type_attr::kFoo.name, ...)`` to register a hook,

- ``TypeAttrColumn(type_attr::kFoo)[type_index]`` to look one up,
