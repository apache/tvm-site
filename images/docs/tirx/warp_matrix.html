One warp · 32 lanes

The warp computes Out = A @ B.T. All 32 lanes copy float16 inputs A and B from global to shared memory, then synchronize at a CTA barrier. Separate ldmatrix instructions load A into ar and B into br. These register fragments feed one warp-wide mma.sync operation. Each lane stores four float32 results, together forming the complete 16 by 8 output tile in global memory.
