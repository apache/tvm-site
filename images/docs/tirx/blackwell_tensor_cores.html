One CTA · 128 threads

The CTA computes Out = A @ B.T. Warp 0 allocates TMEM and thread 0 initializes the completion barrier mbar. All 128 threads copy A to shared memory a; threads 0 through 63 copy B to shared memory b. All threads execute a proxy fence and synchronize. Thread 0 issues four MMA instructions that read a and b directly and accumulate into TMEM d, then commits them to mbar. All threads wait and execute the thread-sync fence. All four warps load TMEM into register fragments frag and wait for the loads. Each thread stores one row of Out. A CTA barrier precedes TMEM release by warp 0.
