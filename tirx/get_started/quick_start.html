Quick Start#

In this chapter, we’ll write and run a small TIRx program using TVMScript, which lets us describe tensor computations with Python syntax. We’ll also inspect the IR that TVMScript creates from the code. The examples use PyTorch tensors; the Build from Source guide explains how to set up TIRx.

Our example computes B[i] = A[i] + 1, where A is the input tensor and B is the output. Both tensors have the same dynamic length n, so the compiled program can handle different input lengths without recompilation.

We’ll show two versions of this program: one for the CPU and one for an NVIDIA GPU. We’ll first compile and run the CPU version using LLVM.

import torch

from tvm_tirx import tirx
from tvm_tirx.script import tirx as T

n = T.dynamic("n")


@T.function
def add_one(A: T.Tensor((n,), T.float32), B: T.Tensor((n,), T.float32)):
    for i in range(n):
        B[i] = A[i] + 1


add_one_compiled = tirx.compile(add_one, target="llvm")
a = torch.arange(10, dtype=torch.float32)
b = torch.empty(a.shape, dtype=a.dtype)
add_one_compiled(a, b)
torch.testing.assert_close(b, a + 1)
print(b)

@T.function turns the add_one definition into IR. The code in add_one loops over the input and writes each result to B. tirx.compile compiles it for the CPU. The compiled function accepts PyTorch tensors directly, and torch.testing.assert_close checks its output.

The same add_one object lets us inspect the program’s IR. We can get the type of parameter A through params[0].ty, then read its symbolic length from shape[0]:

input_type = add_one.params[0].ty
length = input_type.shape[0]

The IR Walkthrough explains these IR objects and how to work with them.

We can also run this computation on an NVIDIA GPU. In addition to LLVM, it still needs CUDA support, an NVIDIA driver, the CUDA toolkit, and cuda-bindings to run.

import torch

from tvm_tirx import tirx
from tvm_tirx.script import tirx as T

n = T.dynamic("n")


@T.function
def add_one(A: T.Tensor((n,), T.float32), B: T.Tensor((n,), T.float32)):
    T.device_entry(launch=T.cuda.LaunchConfig(grid=((n + 255) // 256,), block=(256,)))
    i = T.cuda.block_idx("x") * 256 + T.cuda.thread_idx("x")
    if i < n:
        B[i] = A[i] + 1


add_one_compiled = tirx.compile(add_one, target="cuda")
a = torch.arange(10, dtype=torch.float32, device="cuda:0")
b = torch.empty(a.shape, dtype=a.dtype, device=a.device)
add_one_compiled(a, b)
torch.testing.assert_close(b, a + 1)
print(b)

T.device_entry marks the GPU computation and configures blocks of 256 threads. Each thread handles one element, so the block count is rounded up to cover n elements. The if i < n check keeps extra threads in the last block from accessing the tensors. We compile the function for CUDA with tirx.compile and run it with input and output tensors on "cuda:0", then check the result with PyTorch as in the CPU example.

The complete examples are available as add_one_cpu.py and add_one_cuda.py. You can run them with python add_one_cpu.py and python add_one_cuda.py, respectively.
