Your First TIRx Program

Your First TIRx Program#

In this chapter, we’ll write and run a small TIRx program using TVMScript, TIRx’s Python-based notation for IR, then look at the IR it builds. Our example adds one to each element of a tensor: B[i] = A[i] + 1.

A is the input tensor, and B stores the result. Both tensors have the same dynamic length n. We can call the compiled program with different lengths without recompiling.

With an LLVM-enabled TIRx build, you can download add_one_cpu.py and run python add_one_cpu.py. Here’s the complete program:

import numpy as np

from tvm_tirx import runtime, tirx
from tvm_tirx.script import tirx as T

n = T.dynamic("n")


@T.function
def add_one(A: T.Tensor((n,), "float32"), B: T.Tensor((n,), "float32")):
    for i in range(n):
        B[i] = A[i] + 1


compiled = tirx.compile(add_one, target="llvm")
a = runtime.tensor(np.arange(10, dtype="float32"))
b = runtime.empty(a.shape, a.dtype)
compiled(a, b)
np.testing.assert_allclose(b.numpy(), a.numpy() + 1)
print(b.numpy())

Here, @T.function turns the add_one definition into IR. The code in add_one loops over the input and writes each result to B. tirx.compile compiles it for the CPU, and the NumPy assertion checks its output. We’ll explore the IR objects behind these constructs in the IR Walkthrough.

We can also run this computation on an NVIDIA GPU. In addition to LLVM, this example needs CUDA support, an NVIDIA driver, the CUDA toolkit, and cuda-bindings. You can download add_one_cuda.py and run python add_one_cuda.py. Here’s the complete GPU program:

import numpy as np

from tvm_tirx import cuda, runtime, tirx
from tvm_tirx.script import tirx as T

n = T.dynamic("n")


@T.function
def add_one(A: T.Tensor((n,), "float32"), B: T.Tensor((n,), "float32")):
    T.device_entry(launch=T.cuda.LaunchConfig(grid=((n + 255) // 256,), block=(256,)))
    i = T.cuda.block_idx("x") * 256 + T.cuda.thread_idx("x")
    if i < n:
        B[i] = A[i] + 1


compiled = tirx.compile(add_one, target="cuda")
dev = cuda(0)
a = runtime.tensor(np.arange(10, dtype="float32"), device=dev)
b = runtime.empty(a.shape, a.dtype, device=dev)
compiled(a, b)
np.testing.assert_allclose(b.numpy(), a.numpy() + 1)
print(b.numpy())

Here, T.device_entry marks the GPU computation. Each thread handles one element, and the launch uses enough blocks of 256 threads to cover n elements. The if i < n check skips any extra threads. tirx.compile compiles it for CUDA, and cuda(0) selects the GPU for the input and output tensors. The NumPy assertion checks the result in the same way as the CPU example.
