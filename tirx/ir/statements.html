Statements#

Statements describe variable bindings, tensor writes, and control flow. Extensions can construct and rewrite program bodies with the existing statement nodes. Custom operators can use ir.RegionStmt to define how a group of statements executes.

Statement Nodes#

ir.Stmt is the base class for all statement nodes, including sequences, branches, and loops. It defines the following field:

ir.Location

Source information for diagnostics. Defaults to UnknownLoc and does not affect structural comparison.

Statement Sequences#

A return that uses a bound variable must follow its definition. ir.SeqStmt records the execution order of such statements. For example, consider a function that adds one to its input:

def increment(x):
    result = x + 1
    return result

The following code constructs that function body as IR objects:

from tvm_tirx import ir, tirx
x = ir.Var("x", "int32")
added = x + 1
result = ir.Var("result", added.ty)
body = ir.SeqStmt(
    [
        ir.Bind(result, added),
        ir.Return(result),
    ]
)

The Python variable added holds the expression for x + 1. ir.Var creates the IR variable result, and ir.Bind(result, added) defines it with that expression as its value. added.ty gives result the addition’s int32 type. ir.Return(result) refers to the same variable, and SeqStmt places the definition before the return.

Nested sequences are flattened, and a sequence introduces no scope of its own. Variables defined by Bind are available to subsequent statements in the enclosing scope.

Control Flow and Scope#

Control-flow statement nodes include ir.If for branching, ir.For and ir.While for loops, ir.Break and ir.Continue for loop control, and ir.Return for returning from a function.

The statements inside a branch or loop form its body. Branch bodies are stored in If.then_case and If.else_case, while loop bodies are stored in For.body and While.body. Each body is a SeqStmt and can contain further branches and loops.

For example, this branch returns the incremented value only for positive inputs. Both bodies are normalized to SeqStmt:

branch = ir.If(x > 0, ir.Return(added), ir.Return(x))

If and While use boolean conditions. If requires an explicit else_case argument; pass None when there is no else branch.

A loop instead repeats a body. This loop evaluates each index from zero through three:

i = ir.Var("i", "int32")
loop = ir.For(i, 0, 4, 1, ir.ForKind.DEFAULT, ir.Evaluate(i))

For takes an exclusive end and explicit step and kind arguments. Its variable, bounds, and step must have matching scalar integer types after conversion.

The kind argument controls how loop iterations are executed. ForKind.DEFAULT executes them in order, one after another. See ForKind for the available execution kinds.

Break exits a loop, and Continue starts its next iteration.

Variable scope determines where a definition can be used. The loop defines i inside its body; it cannot be used after the loop. Branch-local definitions similarly stay inside their branch. Each variable object has one definition, and its uses refer to that object.

ir.RegionStmt lets an operator define how a nested body is executed without introducing a new statement class. Its op field refers to the registered ir.Op that defines this behavior. Inputs in args and attrs are evaluated in the enclosing scope. body_params defines variables visible within body; result_vars defines variables available to subsequent statements in the enclosing sequence. See RegionStmt for the operator contract.

To check these definition and scope rules, the body needs the context of a complete function or module. Functions and Modules supplies that context; tirx.analysis.check_well_formed then checks variable and tensor uses and loop control. Invalid uses raise RuntimeError by default; assert_mode=False returns False instead.

The statements_and_functions.py example completes and runs the increment function. See tvm_tirx.ir for statement constructors and tvm_tirx.tirx.analysis for verification APIs.
