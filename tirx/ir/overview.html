IR Overview#

In Your First TIRx Program, we wrote and ran our first TIRx program. To improve efficiency, we need to convert the program into a common intermediate representation (IR) and apply compiler passes to it. In this section, we’ll explore the IR system in tvm-tirx in detail.

The main components of TIRx IR are:

Component

Main classes

Purpose

Example

Expressions

ir.Expr

Represent values and computations.

A[i] + 1

Statements

ir.Stmt

Describe execution order and control flow.

B[i] = A[i] + 1

Types

ir.Type

Describe value properties, such as dtypes and tensor shapes.

T.float32

Functions

ir.BaseFunc, tirx.Function

Define parameters and a computation body.

add_one defined with @T.function.

Modules

ir.IRModule

Organize named functions into a program.

ir.IRModule({"add_one": add_one})

Source locations

ir.Location

Record where IR nodes originate in the source.

The filename and line number of A[i] + 1.

The IR makes values, computations, control flow, and types explicit, allowing analyses and transformations to work with the program’s structure independently of the syntax used to construct it.

TIRx’s C++, Python, and Rust interfaces share a common IR object system through TVM FFI, allowing compiler components written in different languages to work together. Built on shared C++ IR infrastructure, the IR can be extended with custom operators and types, and its existing interfaces can be used to build custom analyses, transformation passes, and backends.

What to Read Next#

After the add-one example in Your First TIRx Program, this walkthrough uses a bias + sigmoid program to introduce symbolic shapes and scalar computations. It computes Y[i, j] = 1 / (1 + exp(-(X[i, j] + bias[j]))). Download tvmscript_sigmoid.py and run python tvmscript_sigmoid.py with an LLVM-enabled TIRx build.

  • The Types and Expressions chapter explains how values, computations, and tensor shapes are represented.

  • The Statements chapter covers statement bodies with bindings, tensor writes, branches, and loops.

  • The Operators and Calls chapter introduces registered operators and function calls.

  • The Functions and Modules chapter shows how functions are defined and organized in modules.

  • The Printing and Parsing chapter covers TVMScript definitions, program generation, and conversion between source text and IR.
