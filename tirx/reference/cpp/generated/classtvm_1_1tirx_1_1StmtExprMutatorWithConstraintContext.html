class StmtExprMutatorWithConstraintContext : public tvm::tirx::ObjectMutatorWithConstraintContext#

Native virtual mutation hooks over one structural constraint engine.

Override Mutate_ for known nodes or Mutate for general dispatch. Allocate with ffi::make_object; typed entry points preserve expression/statement categories. Defaults share matching native expression bodies and delegate scope-sensitive nodes to the same hooks as StructuralMapWithConstraintContext and StructuralMutateWithConstraintContext, with one context and one variable-remap environment. Unknown node types use structural fallback.

Forward the inherited mode to child mutations. Entry overrides must preserve inherited denial and check uniqueness before writing. The default entry does so before calling a node hook. Errors propagate without restoring constraints, in-place IR changes, or identity remaps; discard the context after failure. 

struct Rewrite : StmtExprMutatorWithConstraintContext {
using StmtExprMutatorWithConstraintContext::Mutate_;
  ffi::UnchangedOr<PrimExpr> Mutate_(const prim::AddObj* node,
                                   ffi::InplaceMode mode) override {
// Inspect constraints here; delegate to retain default recursive behavior.
return StmtExprMutatorWithConstraintContext::Mutate_(node, mode);
  }
};
auto mutator = ffi::make_object<Rewrite>();
auto result = mutator->Mutate(stmt);
