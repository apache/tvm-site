Function Documentation#

ForFrame tvm::script::ir_builder::ir::For(ForKind kind, PrimExpr start, PrimExpr stop, ffi::Optional<PrimExpr> step = std::nullopt, ffi::Optional<PrimType> dtype = std::nullopt, ffi::Optional<ffi::Map<ffi::String, Any>> annotations = std::nullopt)#

Construct a For statement of the given kind.

Parameters:

  • kind – The kind of iteration.

  • start – The minimum value of iteration.

  • stop – The maximum value of iteration.

  • step – The optional step value of iteration.

  • dtype – The optional dtype of the loop var (“int32” or “uint32”). When omitted it is inferred from the bounds.

  • annotations – The optional annotations of the For statement.

Returns:

The ForFrame.
