class TargetKindDef#

Temporary fluent builder for registering a target kind.

The registry retains the canonical kind after this builder is destroyed. Group related definitions inside TVM_FFI_STATIC_INIT_BLOCK(): 

TVM_FFI_STATIC_INIT_BLOCK() {
TargetKindDef("llvm")
      .set_default_device_type(kDLCPU)
      .set_default_keys({"cpu"})
      .def_option<ffi::String>("mcpu");
}
