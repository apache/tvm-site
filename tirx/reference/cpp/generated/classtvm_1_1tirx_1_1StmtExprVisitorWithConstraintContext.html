class StmtExprVisitorWithConstraintContext : public tvm::tirx::ObjectVisitorWithConstraintContext#

Native virtual node hooks using one constraint-aware structural visitor. Allocate with ffi::make_object<Derived>(). Override Visit_ for a known node or Visit for general dispatch. Defaults share matching native expression bodies and delegate scope-sensitive nodes to structural constraint hooks. A hook owns its descent; calling the qualified parent hook runs it once with the same context. Unknown types use structural fallback, which can reach specialized descendants.
