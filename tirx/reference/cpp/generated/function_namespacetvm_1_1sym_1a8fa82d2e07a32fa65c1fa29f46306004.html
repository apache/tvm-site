IntSet tvm::sym::Intersect(const IntSet &lhs, const IntSet &rhs, const Analyzer &analyzer)#

Intersect two integer sets using the analyzer’s bindings and constraints.

Parameters:

  • lhs – The first set.

  • rhs – The second set.

  • analyzer – The analyzer used to prove whether the intersection is empty.

Returns:

Nothing if emptiness is proved, or the intersected bounds otherwise.
