class StmtExprMutatorWithAnalyzer : public tvm::tirx::StmtExprMutator#

IRMutator with an analyzer context.

This class can sub-classed by ir mutators that need an analyzer. It will populates scope-related info such as bounds of loop-variables and constraints for the analyzer, so that the child class can do accurate context-dependent analysis.
