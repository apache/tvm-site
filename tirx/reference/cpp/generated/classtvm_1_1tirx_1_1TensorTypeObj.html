class TensorTypeObj : public tvm::TypeObj#

Structural type of a TIRx tensor variable.

A tensor value is an ordinary VarObj whose ExprObj::ty is TensorType. TensorType owns the immutable access contract. The physical pointer is deliberately not stored here; it is obtained with tensor_data_ptr(TensorVar) and is bound by the surrounding tensor definition.

bool HasDefaultLayout(ffi::Optional<sym::Analyzer> analyzer = std::nullopt) const#

Whether the layout is provably equivalent to implicit row-major storage.

An absent layout returns true. Explicit layouts must have zero origin and contiguous memory-only tiles covering exactly the tensor shape, without replicas. Equivalent split tiles and arbitrary strides on unit extents are accepted. Deep expression equality is tried before symbolic proof. A supplied analyzer retains its constraints; otherwise one is created only on the first proof fallback.
