Function Documentation#

template<ffi::WalkOrder order, typename ...Callbacks>
ffi::Any tvm::tirx::StructuralMapWithConstraintContext(ffi::Any root, Callbacks&&... callbacks)#

Map with (value, const sym::ConstraintContext& [, def_region_kind]) callbacks. Callbacks return a replacement, Unchanged, or Expected thereof; they must not mutate their input. Pre/post behavior is that of ffi::StructuralMap. Pass std::move(root) to permit reuse; shared roots still copy. The position is restored before a scoped node’s post callback. See the object documentation for timing.
