Struct AnyView 

Source 
pub struct AnyView<'a> { /* private fields */ }
Expand description

A borrowed, type-erased FFI value.

AnyView holds any FFI value, such as an integer, a string or an object, without owning it: it does not retain objects, and its lifetime 'a keeps it from outliving the value it borrows. It is Copy and is the argument type of FFI calls. Convert it into an Any to own the value.

§Examples

use tvm_ffi::{Any, AnyView, Array};

let array = Array::from_vec(vec![1_i64, 2, 3]);
let view = AnyView::from(&array);
assert_eq!(view.downcast_ref::<Array<i64>>().unwrap().len(), 3);

let owned = Any::from(view);
assert_eq!(Array::<i64>::try_from(owned)?.len(), 3);

Construct a borrowed view from its ABI representation.

§Safety

data.type_index must describe the payload, and the caller must keep every resource it references alive for the view’s complete lifetime.

kTVMFFIObjectRValueRef carries a further obligation: v_ptr must point to a writable slot the caller uniquely owns, holding one strong reference. Owning the view takes that reference and writes null back through the pointer, so the view must be converted at most once and no other access to the slot may overlap the conversion.

Source

pub fn downcast_ref<T: DowncastRefFromAny>(&self) -> Option<&T>

Borrow the viewed value as T when it holds one, without copying it.

T is an object type such as ArrayObj, a managed reference such as Array<i64>, or a value stored in place such as String or i64. The check is strict and never converts, unlike TryFrom. The borrow does not change any reference count and is tied to this view, which holds its own copy of the value’s cell.

§Returns

The borrowed value, or None.

See also Any::downcast_ref.
