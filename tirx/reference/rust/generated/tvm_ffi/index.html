Rust bindings of TVM FFI, the open ABI and FFI for machine learning systems.

Values cross the boundary as Any and AnyView. Objects, such as Array, Map, Tensor and types defined with rs_object, are reference counted and shared with C++ and Python. A Function is callable from every language, and an Error raised in one arrives in the others.

§Examples

use tvm_ffi::{Array, Function, Result};

let sum = |xs: Array<i64>| -> Result<i64> { Ok(xs.iter().sum()) };
Function::register_global_typed("my_ext.sum", sum, "Sum the elements.")?;

let sum = Function::get_global("my_ext.sum")?;
let total = sum.call_tuple((Array::from_vec(vec![1_i64, 2, 3]),))?;
assert_eq!(i64::try_from(total)?, 6);

§FFI contracts

Some guarantees rest on contracts every language keeps, which Rust cannot check:

  • An ffi.String holds UTF-8, so String::as_str does not validate it.
  • Types, functions and attributes register during static initialization, such as in a static_init_block!, before other threads read them: readers of the runtime’s tables take no lock.
  • A type key describes the same type in every library that declares it; see rs_object.
  • A TensorView received as a function argument is valid only during the call, and so is an Any holding a DLTensor* converted from it or from an AnyView.

static_init
Static init blocks: code that runs when the program or library that holds it loads. The blocks of a program or library are gathered at link time, wherever in it they are, and a constructor runs them when it loads. Once Python loads a library built on this crate, by any means, it sees what the blocks registered, such as global functions. A block that several libraries of a process have, as each links its own copy of a crate they share, runs once. See static_init_block!.
string
String and Bytes, immutable reference-counted strings.
type_traits
AnyCompatible, how a Rust type converts to and from FFI values.

impl_object_ref_downcast_ref
Implement the in-place downcast_ref borrows (array[i], Any::downcast_ref, ObjectRefCore::downcast_ref) for each listed object reference type. #[derive(ObjectRef)] emits it; a reference that implements ObjectRefCore by hand calls it.
impl_object_ref_upcast
Implement zero-copy conversions from a derived object reference to one of its base object-reference types: From<Source> and From<&Source> into Target, AsRef<Target>, which borrows a &Source as &Target without touching the reference count, and IntoObjectRef<Target> for Source and &Source, and TypeSubsumes<Source> for Target, so Array::upcast turns an Array<Source> into an Array<Target>. It also implements the strict downcast back, TryFrom<Target> and TryFrom<&Target> for Source, which return a TypeError naming both types.
into_typed_fn
Wrap a Function as a typed closure with the given signature: into_typed_fn!(func, Fn(A, B) -> Result<R>).
match_any
Match the runtime type of a value, the way match matches an enum.
static_init_block
Run code when the program or library that holds it loads, the Rust form of TVM_FFI_STATIC_INIT_BLOCK. The body is the body of a function that returns Result<()>: it registers what the library defines, such as global functions, and stops at its first error, which ? returns. A body whose statements all end in ; returns Ok(()); one that ends in an expression returns it, a Result<()>.
