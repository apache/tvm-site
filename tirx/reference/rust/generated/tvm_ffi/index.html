  • static_init
    Static init blocks: code that runs when the program or library that holds it loads, as a C++ TVM_FFI_STATIC_INIT_BLOCK does. The blocks of a program or library are gathered at link time, wherever in it they are, and a constructor runs them when it loads. Once Python loads a library built on this crate, by any means, it sees what the blocks registered, as it sees the registrations of a C++ library. A block that several libraries of a process have, as each links its own copy of a crate they share, runs once. See static_init_block!.

  • static_init_block
    Run code when the program or library that holds it loads, as a C++ TVM_FFI_STATIC_INIT_BLOCK does. The body is the body of a function that returns Result<()>: it registers what the library defines, such as global functions, and stops at its first error, which ? returns. A body whose statements all end in ; returns Ok(()); one that ends in an expression returns it, a Result<()>.
