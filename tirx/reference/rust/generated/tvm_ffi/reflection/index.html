Module reflection 

Source
Expand description

Object reflection: look up the methods, fields and type attributes of registered types; register Rust object types with ObjectDef, type attributes with TypeAttrDef and enum values with EnumDef; call the typed hooks that attributes hold with NativeFunction.

NativeFunction
A typed hook that a type attribute, an enum attribute or another registry slot holds: a native function, called directly through the C ABI, or a packed Function registered in its place.
ObjectDef
Registers the reflection of the object type N: the metadata, each #[reflect] field, the methods and the type attributes.
TypeAttrColumn
A registry-owned type-attribute column indexed by runtime type.
TypeAttrDef
Registers type attributes of the object type T, each as soon as set_attr names it, for every language to read with TypeAttrColumn.
