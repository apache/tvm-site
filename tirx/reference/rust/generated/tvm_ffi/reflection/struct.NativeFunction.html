Struct NativeFunction 

Source 
pub struct NativeFunction<Args, R = ()> { /* private fields */ }
Expand description

A typed hook that a type attribute, an enum attribute or another registry slot holds: a native function, called directly through the C ABI, or a packed Function registered in its place.

Args is the tuple of argument types and R the result type, as in Fn(Args) -> R: a hook that checks a pair is a NativeFunction<(&MyPairObj,)>, and one that measures it a NativeFunction<(&MyPairObj,), i64>. An argument is a borrowed object (&MyPairObj), a borrowed managed reference (&Array<T>) or &Any, and a native function receives its address, which C++ declares as const MyPairObj*, const Array<T>& or const Any&.

A native function carries no signature at run time, so the slot declares it. Reading a hook with from_any is unsafe, the caller vouching for the signature, and then calling it is safe. Building a hook from a Rust function with into() is safe; storing it, with TypeAttrDef::set_native_fn_attr or EnumDef::set_native_fn_attr, or converting it to Any for another registry with into_any, is unsafe, the caller vouching that the slot’s callers use exactly this signature.

§Examples

use tvm_ffi::reflection::{NativeFunction, TypeAttrColumn, TypeAttrDef};
use tvm_ffi::{rs_object, Object, ObjectArc, ObjectCore, Result};

#[rs_object(type_key = "my_ext.MyPair")]
pub struct MyPairObj {
    base_: Object,
    first: i64,
    second: i64,
}

fn sum(pair: &MyPairObj) -> Result<i64> {
    Ok(pair.first + pair.second)
}

let hook: NativeFunction<(&MyPairObj,), i64> = sum.into();
// SAFETY: `my_ext.sum` holds `i64(const MyPairObj*)` hooks.
unsafe { TypeAttrDef::<MyPairObj>::new().set_native_fn_attr("my_ext.sum", hook)? };

let stored = TypeAttrColumn::lookup("my_ext.sum").unwrap().get(MyPairObj::type_index()).unwrap();
// SAFETY: `my_ext.sum` holds `i64(const MyPairObj*)` hooks.
let sum: NativeFunction<(&MyPairObj,), i64> = unsafe { NativeFunction::from_any(stored)? };
let pair = ObjectArc::new(MyPairObj { base_: Object::new(), first: 1, second: 2 });
assert_eq!(sum.call((&*pair,))?, 3);

Call the hook with args.

§Arguments

§Returns

§Errors

Panics if an object argument is not managed, such as an object built on the stack: the hook may retain it.

pub unsafe fn from_any(value: Any) -> Result<Self>

Read the hook that value holds: a non-null opaque pointer to a native function, or a packed Function.

§Arguments
  • value - The hook, as its registry slot holds it.
§Returns

The hook, typed with Args and R.

§Errors

Returns a TypeError if value is neither a non-null opaque pointer nor a Function.

§Safety

A native function in value must take Args and return R, as the code that registers it in the slot declares. A packed Function is called through checked conversions and has no such requirement.

See also NativeFunction.

Source

pub unsafe fn into_any(self) -> Any

The hook as a registry slot holds it: the opaque pointer of a native function, or the packed Function.

This is how a registry other than a type or enum attribute stores a hook; from_any reads it back.

§Safety

Every reader of the slot that stores the result calls it with exactly Args and reads R: a native caller calls the function pointer unchecked.
