Expand description

Implement zero-copy conversions from a derived object reference to one of its base object-reference types: From<Source> and From<&Source> into Target, AsRef<Target>, which borrows a &Source as &Target without touching the reference count, and IntoObjectRef<Target> for Source and &Source. It also implements the strict downcast back, TryFrom<Target> and TryFrom<&Target> for Source, which return a TypeError naming both types.

§Safety

The declaration is trusted, as an unsafe impl is, hence the unsafe_ name: target must be a registered base of source, and every source must satisfy the target reference invariants. An incorrect declaration makes the generated safe conversions unsound. The Rust stub generator writes these from the registered type hierarchy.
