Trait IntoArg 

Source 
pub trait IntoArg<T> {
    type Output: Borrow<T>;

    // Required methods
    fn into_arg(self) -> Self::Output;
    fn into_owned(self) -> T;
}
Expand description

A T, a &T or a subtype of T, taken where a T is expected; a &str or &[u8] converts into a String or Bytes.

into_arg returns a T or a &T without changing a reference count, but those two conversions allocate; into_owned moves an owned value and clones only a borrowed one, as Cow::into_owned.
