Trait ContainerElement

pub trait ContainerElement: Ops { }
Expand description

A value an FFI container such as Array or Map holds: every AnyCompatible type, and Any.

Use it as the bound of code generic over container elements, as Array<T: ContainerElement> is. The trait is sealed: implement AnyCompatible instead, and the type is an element.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
