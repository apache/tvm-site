tvm_ffi::function

Struct Function 

Source 
pub struct Function { /* private fields */ }
Expand description

A type-erased callable that works across languages.

A Function takes AnyView arguments and returns an Any. Make one from a Rust closure with from_typed, look one up by name with get_global, and call it with call_tuple or call_packed. into_typed_fn! turns it back into a typed closure.

§Examples

use tvm_ffi::{Function, Result};

let add = Function::from_typed(|x: i64, y: i64| -> Result<i64> { Ok(x + y) });
let sum = i64::try_from(add.call_tuple((1_i64, 2_i64))?)?;
assert_eq!(sum, 3);

A Function may be called from any thread, so a Rust callback must be Send + Sync; a callback holding an Rc is rejected. The callee’s own thread safety, for C++ functions and the objects they touch, is that of its implementation.

ⓘ
use std::rc::Rc;
let count = Rc::new(0_i64);
tvm_ffi::Function::from_typed(move || -> tvm_ffi::Result<i64> { Ok(*count) });

pub fn get_global(name: &str) -> Result<Function>

Look up the global function registered as name.

§Arguments
  • name - The name of the function, such as "my_ext.double".
§Returns

The global function.

§Errors

Returns an error if no function is registered as name, as C++ Function::GetGlobalRequired throws and Python get_global_func raises by default. Probe with .ok() where a missing function is expected.

use tvm_ffi::Function;
let double = Function::from_typed(|x: i64| -> tvm_ffi::Result<i64> { Ok(x * 2) });
Function::register_global("my_ext.double", double)?;
let double = Function::get_global("my_ext.double")?;
assert_eq!(i64::try_from(double.call_tuple((21_i64,))?)?, 42);

See also register_global_typed.

pub fn register_global(name: &str, func: Function) -> Result<()>

Register a function as a global function, which every language can then look up by name.

The function’s metadata records the type schema of an untyped function, as C++ refl::GlobalDef().def_packed does. Use Function::register_global_typed to record the parameter and return types of a typed function, and a doc string.

§Arguments
  • name - The name of the function.
  • func - The function to register.
§Returns

Ok(()) once the function is registered.

§Errors

Returns an error if the registration fails.

See also get_global.

pub fn register_global_typed<F, I, O>( name: &str, func: F, doc: &str, ) -> Result<()>
where F: AsPackedCallable<I, O> + Send + Sync + 'static,

Register a typed function as a global function, with a doc string.

As C++ refl::GlobalDef().def does, the function’s metadata records its type schema, which tvm_ffi.get_global_func_metadata and the stub generator read. An empty doc records no doc string.

§Arguments
  • name - The name of the function.
  • func - The typed function to register, as for Function::from_typed.
  • doc - The doc string of the function.
§Returns

Ok(()) once the function is registered.

§Errors

Returns an error if the registration fails.

use tvm_ffi::{Function, Result};
let add = |x: i64, y: i64| -> Result<i64> { Ok(x + y) };
Function::register_global_typed("my_ext.add", add, "Add two integers.")?;

See also get_global.

pub fn from_packed<F>(func: F) -> Self
where F: Fn(&[AnyView<'_>]) -> Result<Any> + Send + Sync + 'static,

Construct a function from a packed function, which takes its arguments as a slice.

Use it for a variable number of arguments; otherwise from_typed converts the arguments for you. Report errors by returning them. A panic in func is caught and raised to the caller as an InternalError, but panicking is discouraged.

§Arguments
  • func - The packed function, of signature Fn(&[AnyView]) -> Result<Any>.
§Returns

The function.

use tvm_ffi::{Any, AnyView, Function, Result};
let count = Function::from_packed(|args: &[AnyView]| -> Result<Any> {
    Ok(Any::from(args.len() as i64))
});
assert_eq!(i64::try_from(count.call_tuple((1_i64, true))?)?, 2);

See also Function.

pub fn from_typed<F, I, O>(func: F) -> Self
where F: AsPackedCallable<I, O> + Send + Sync + 'static,

Construct a function from a typed function.

Each argument is converted to its parameter type, and a mismatch raises a TypeError to the caller. Report errors by returning them. A panic in func is caught and raised to the caller as an InternalError, but panicking is discouraged.

§Arguments
  • func - The typed function, of signature Fn(T0, T1, ...) -> Result<O>.
§Returns

The function.

use tvm_ffi::{Function, Result};
let scale = Function::from_typed(|x: f64, factor: f64| -> Result<f64> { Ok(x * factor) });
assert_eq!(f64::try_from(scale.call_tuple((2.0_f64, 1.5_f64))?)?, 3.0);

See also Function.

pub unsafe fn from_extern_c( handle: *mut c_void, safe_call: TVMFFISafeCallType, deleter: Option<unsafe extern "C" fn(*mut c_void)>, ) -> Result<Self>

§Safety

handle must be a valid pointer (or null) that is compatible with safe_call and deleter. The caller must ensure the handle outlives the returned Function (or that deleter properly frees it).

§Errors

Returns an error if the runtime cannot allocate the function. The function then does not take handle: deleter is not called, and the caller still owns handle.
