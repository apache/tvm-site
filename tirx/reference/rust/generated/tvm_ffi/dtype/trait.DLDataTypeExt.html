Name conversions of a DLDataType.

Required Methods§

Source

fn to_string(&self) -> String

Return the name of the data type, such as "int32", "float64" or "int8x4" (bits and lanes), the name every language uses for it.

use tvm_ffi::{DLDataType, DLDataTypeExt};
let dtype = DLDataType::try_from_str("float16")?;
assert_eq!(dtype.to_string(), "float16");

fn try_from_str(dtype_str: &str) -> Result<Self>

Parse a data type from its name, the inverse of to_string.
