tvm_ffi::collections::array

Struct Array 

Source 
pub struct Array<T> { /* private fields */ }
Expand description

An immutable, reference-counted sequence of T, shared with C++ and Python as ffi.Array.

Cloning an Array is cheap: it shares the same elements. Use List for a sequence that changes in place.

§Examples

use tvm_ffi::Array;

let array = Array::from_vec(vec![1_i64, 2, 3]);
assert_eq!(array.len(), 3);
assert_eq!(array.get(1)?, 2);
assert!(array.get(3).is_err());

let doubled: Array<i64> = array.iter().map(|x| x * 2).collect();
assert_eq!(doubled.iter().copied().collect::<Vec<_>>(), vec![2, 4, 6]);

pub fn iter(&self) -> Iter<'_, T> ⓘ

Return an iterator that borrows each element in place, without a reference-count bump, as array[i] does.

Element types stored in another representation, such as bool or i32 (held as i64), iterate by value instead: for x in array.

use tvm_ffi::Array;
let array = Array::from_vec(vec![1_i64, 2, 3]);
assert_eq!(array.iter().sum::<i64>(), 6);
