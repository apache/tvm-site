tvm_ffi::collections::array

Struct Array 

Source 
pub struct Array<T> { /* private fields */ }
Expand description

A reference-counted sequence of T with value semantics, passed across languages as ffi.Array.

Cloning an Array is cheap: it shares the same elements. The mutators (push, insert, pop, truncate, set) are copy-on-write: they copy the elements when the array is shared, and write in place when this handle is the only reference, so other handles never see the change. Use List for a sequence whose changes all handles see.

§Examples

use tvm_ffi::Array;

let mut array = Array::from_vec(vec![1_i64, 2, 3]);
assert_eq!(array.len(), 3);
assert_eq!(array.get(1)?, 2);
assert!(array.get(3).is_err());

let snapshot = array.clone();
array.push(4);
assert_eq!(array.len(), 4);
assert_eq!(snapshot.len(), 3);

let doubled: Array<i64> = array.iter().map(|x| x * 2).collect();
assert_eq!(doubled.iter().copied().collect::<Vec<_>>(), vec![2, 4, 6, 8]);

pub fn upcast<U: TypeSubsumes<T>>(self) -> Array<U>

View this array as an Array<U> without a copy, as C++ Array<U>(const Array<T>&) does for a base U of T.

It is a method, not From: From<Array<T>> for Array<U> would overlap From<T> for T at T = U (E0119), and a crate that defines T and U cannot implement it for Array either (orphan rule, E0117).

use tvm_ffi::object::{ObjectRef, ObjectRefCore};
use tvm_ffi::{Array, Shape};

let shapes = Array::from([Shape::from([1_i64, 2])]);
let objects: Array<ObjectRef> = shapes.clone().upcast();
assert!(objects[0].same_as(&shapes[0]));

impl<T: ContainerElement + Clone + RefFromAnyUnchecked> Array<T>

Source

pub fn iter(&self) -> Iter<'_, T> ⓘ

Return an iterator that borrows each element in place, without a reference-count bump, as array[i] does.

Element types stored in another representation, such as bool or i32 (held as i64), iterate by value instead: for x in array.

use tvm_ffi::Array;
let array = Array::from_vec(vec![1_i64, 2, 3]);
assert_eq!(array.iter().sum::<i64>(), 6);
