Struct Map 

Source 
pub struct Map<K, V> { /* private fields */ }
Expand description

An immutable, reference-counted map from K to V, passed across languages as ffi.Map.

Cloning a Map is cheap: it shares the same entries.

§Examples

use tvm_ffi::{Map, String};

let map: Map<String, i64> = [(String::from("a"), 1), (String::from("b"), 2)]
    .into_iter()
    .collect();
assert_eq!(map.len(), 2);
assert_eq!(map.get(&String::from("b"))?, Some(2));
assert_eq!(map.get(&String::from("c"))?, None);

Source

pub fn get(&self, key: &K) -> Result<Option<V>>

Looks up key, returning Ok(None) if it is absent.

§Errors

Returns an error if the runtime cannot look key up, such as when it is not hashable, or if the value is not a V.

The result for a key of another type than the map’s keys is unspecified: it currently reads as absent, since a lookup hashes the key instead of reading a stored one. Debug builds assert against it.
