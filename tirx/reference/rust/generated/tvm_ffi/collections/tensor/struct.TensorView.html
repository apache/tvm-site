Struct TensorView 

Source 
pub struct TensorView<'a> { /* private fields */ }
Expand description

A non-owning view of a tensor: a pointer to a DLTensor.

A function argument of this type accepts both a borrowed DLTensor* (type index kTVMFFIDLTensorPtr, how C callers pass tensors) and a Tensor object (type index kTVMFFITensor), and is passed on as a DLTensor*. Prefer it over Tensor for arguments of exported functions that only read a tensor’s metadata and data.

The view does not keep anything alive: its lifetime 'a ties it to what it borrows. For the same reason, a view cannot be moved into an owned Any, which could outlive it; use Tensor instead. Neither misuse compiles:

ⓘ
use tvm_ffi::{Tensor, TensorView};
let view = {
    let tensor = Tensor::from_slice(&[1.0_f32], &[1]).unwrap();
    TensorView::from(&tensor)
};
view.ndim();
ⓘ
use tvm_ffi::{Any, Tensor, TensorView};
let tensor = Tensor::from_slice(&[1.0_f32], &[1]).unwrap();
let _ = Any::from(TensorView::from(&tensor));

A view received as an argument of an exported function is valid only during the call. The function may name any lifetime for it, TensorView<'static> included, so the compiler does not stop it from being kept past the call; doing so is undefined behavior.
