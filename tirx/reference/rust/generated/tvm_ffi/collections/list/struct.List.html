tvm_ffi::collections::list

Struct List 

Source 
pub struct List<T> { /* private fields */ }
Expand description

A mutable, reference-counted sequence of T, shared with C++ and Python as ffi.List.

Cloning a List is cheap and yields a handle to the same list, so a change through one handle is seen through every other. Methods take &self.

§Examples

use tvm_ffi::List;

let list = List::<i64>::new();
list.push(1)?;
list.push(2)?;
assert_eq!(list.get(1)?, 2);
assert_eq!(list.len(), 2);
