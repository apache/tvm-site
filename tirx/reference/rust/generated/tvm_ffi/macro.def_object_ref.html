Expand description

Define the managed reference to an object type, as C++ TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE does.

def_object_ref!(TypeName, ParentType, ObjectName) defines TypeName, a derive(ObjectRef) type that holds an ObjectName. It dereferences to ObjectName, and an ObjectName converts into it.

§Arguments

  • TypeName - The reference type to define. Attributes and visibility before it go on the struct.
  • ParentType - The reference to the parent’s object, ObjectRef for a type under ffi.Object. TypeName converts into it by impl_object_upcast!, and &TypeName borrows as &ParentType through AsRef; a conversion into a further ancestor takes its own impl_object_upcast!.
  • ObjectName - The object type.
  • crate = path - Optional, after ObjectName: where the generated code finds tvm-ffi, as for rs_object.

§Examples

use tvm_ffi::object::ObjectRef;
use tvm_ffi::{def_object_ref, rs_object, Object};

#[rs_object("my_ext.MyPair", final)]
pub struct MyPairObj {
    base: Object,
    pub first: i64,
    pub second: i64,
}

def_object_ref!(pub MyPair, ObjectRef, MyPairObj);

let pair = MyPair::from(MyPairObj::new(Object::new(), 1, 2));
assert_eq!(pair.first + pair.second, 3);
let _borrowed: &ObjectRef = pair.as_ref();
let _parent: ObjectRef = pair.into();
