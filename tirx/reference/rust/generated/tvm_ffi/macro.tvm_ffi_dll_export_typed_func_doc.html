Macro tvm_ffi_dll_export_typed_func_doc

macro_rules! tvm_ffi_dll_export_typed_func_doc {
    ($name:ident, $doc:expr) => { ... };
}
Expand description

Macro to export the doc string of a function exported with tvm_ffi_dll_export_typed_func!, as C++ TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC does

With the export-metadata feature, the doc string is exported as __tvm_ffi__doc_<name>, which Module::GetFunctionDoc and the stub generator read. Without it, as C++ without TVM_FFI_DLL_EXPORT_INCLUDE_METADATA, the macro exports nothing, but still checks that the doc string is a string constant. The macro never exports the function itself.

§Arguments

  • $name - The name the function is exported as
  • $doc - The doc string, a string literal

§Example

use tvm_ffi::*;

fn add(a: i64, b: i64) -> Result<i64> { Ok(a + b) }

tvm_ffi_dll_export_typed_func!(add, add);
tvm_ffi_dll_export_typed_func_doc!(add, "Add two integers and return the sum.");
