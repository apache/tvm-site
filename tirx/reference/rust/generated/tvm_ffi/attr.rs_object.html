Attribute Macro rs_object 

#[rs_object]
Expand description

Define an object type in Rust, as Python’s py_class does.

#[rs_object("type.Key", options...)] registers the struct as an object type with the reflection of every field, so that C++ structural equality and hashing, repr, deep copy and Python see the fields. The first field, base, is the parent’s object, as the base class of a C++ object is: base: Object for a type under ffi.Object. Define the managed reference with def_object_ref!.

The macro adds to the struct:

  • #[repr(C)] and Deref to the parent’s object, so obj.field reads the fields of both.
  • MyPairObj::new(base, fields...), which takes the fields in order: a scalar (bool, an integer or a float) as its own type, so that a literal infers as it, and any other field from anything that converts into it.

§Arguments

  • "type.Key" - The type key.
  • final - The type has no subtypes.
  • s_eq_hash_kind = "TreeNode" - The SEqHashKind of structural equality; by default the parent’s.
  • child_slots = N, child_slots_can_overflow = bool - Type indices kept for subtypes; 0 and true by default.
  • reflection = path - A fn(&mut ObjectDef<Self>) that registers the type’s methods.
  • crate = path - Where the generated code finds tvm-ffi, for a crate that depends on it only through a re-export; by default tvm_ffi.

A field takes #[reflect(writable, seq_hash_ignore, ...)] for the FieldFlags of those names, and name = "..." or doc = "..." to register it under another name or with a doc string, by default its /// comment.

§Requirements

A field’s type must implement AnyCompatible and Clone; an init_off field’s type must take all-zero bytes as a value. The parent’s object must implement ShallowCopy and UnsafeInit, as rs_object types and non-final C++ types bound by tvm-ffi-stubgen do. The type registers on its first type_index(), with its fields, methods, __ffi_new__ and, unless the methods define it, __ffi_init__.

§Examples

use tvm_ffi::object::ObjectRef;
use tvm_ffi::{def_object_ref, rs_object, Object};

#[rs_object("my_ext.MyPair", final)]
pub struct MyPairObj {
    base: Object,
    pub first: i64,
    #[reflect(seq_hash_ignore)]
    pub second: tvm_ffi::String,
}
def_object_ref!(pub MyPair, ObjectRef, MyPairObj);

let pair = MyPair::from(MyPairObj::new(Object::new(), 1, "one"));
assert_eq!(pair.first, 1);
assert_eq!(pair.second.as_str(), "one");
