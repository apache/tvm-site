pub unsafe trait ObjectDerivesFrom<A, Depth> { }
Expand description

The object type Self is A or derives from it through its chain of ObjectCore::Parents, so a Self is a valid A.

Depth is the number of parent steps from Self to A, a type from marker that the compiler infers.

§Safety

The blanket implementations are the only sound ones: do not implement it.
