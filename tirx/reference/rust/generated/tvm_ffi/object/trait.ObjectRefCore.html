Expand description

A managed object reference: the category of types such as ObjectRef, Array<T> and every #[derive(ObjectRef)] type, with the operations every reference supports: identity (same_as) and strict casts between reference types, which check the object’s runtime type and never convert. downcast_ref borrows in place, and downcast takes the reference, as std’s dyn Any::downcast_ref and Box<dyn Any>::downcast do. Upcasts are From/Into, which #[derive(ObjectRef)] and unsafe_impl_object_upcast! generate.

The derive implements it. data, into_data and from_data are the handle plumbing the FFI uses, called as associated functions; the trait is unsafe to implement because they move the reference’s internals.

§Safety

data, into_data, and from_data must preserve the same object allocation and form an ownership-preserving round trip. That allocation must start with a valid TVMFFIObject header whose registered object-range runtime type index correctly describes its layout and inheritance.

When Self also implements AnyCompatible, copy_to_any_view must produce a non-owning view, while move_to_any must transfer ownership of the same object pointer and dynamic type index. move_from_any_after_check must be able to reclaim that owned representation exactly once, and a true check_any_strict result must guarantee that both after-check constructors are valid for it.

§Safety

In addition to containing a valid ContainerType allocation, data must satisfy every semantic invariant imposed by Self. This matters for zero-state views that share a container type but accept only a subset of its values, such as a typed expression view.

fn downcast_ref<T: DowncastRefFromObject>(&self) -> Option<&T>

Borrow the underlying object as T when it is one.

T is an object type such as FooObj, or a managed reference such as Foo: &Expr borrows as &Add when the expression is an Add. Unrelated types return None. Unlike downcast, this method neither consumes the reference nor changes the object’s reference count. The returned borrow cannot outlive self. See crate::Any::downcast_ref for an example.

Source

fn downcast<B>(self) -> Result<B, Self>
where B: ObjectRefCore,

Take self as the reference type B when its object is one, without copying the object or changing its reference count.

B is a subtype, or a parameterized container such as Array<i64>, whose elements are checked too. On a mismatch the reference is returned unchanged, so another type can be tried. For ?, use the TryFrom that each upcast provides, which returns a TypeError instead.

use tvm_ffi::{object::ObjectRef, Array, ObjectRefCore};
let object: ObjectRef = Array::from_vec(vec![1_i64]).into();
let object = object.downcast::<Array<f64>>().unwrap_err();
let array: Array<i64> = object.try_into()?;
assert_eq!(array.len(), 1);

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
