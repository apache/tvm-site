Expand description

Convert a dispatcher, a callback, or a tuple of them, into a Dispatcher for the argument tuple Args and result Ret; the traversals take any of these inputs.

  • An owned D or a borrowed &mut D keeps D as the Target, and must have exactly that signature.
  • A callback takes a leading prefix of one to four of the arguments, and its first parameter selects what it matches, as for a #[dispatch] handler: an FFI value, a borrowed object node or AnyView, or a typed MutationView for mutation. It is passed by value, & or &mut.
  • A tuple, possibly nested, tries its links in order. Only an outer None moves on to the next link; an error or an inner None stops.

M marks the input form and is inferred; when calling into_dispatcher directly, give Args and Ret. See also #[dispatch].

use tvm_ffi::{Any, AnyView, Dispatcher, IntoDispatcher, Result};
let callbacks = (|value: i64| Any::from(value + 1), |_value: AnyView<'_>| Any::new());
let mut dispatcher = IntoDispatcher::<(AnyView<'_>,), Option<Result<Any>>, _>::into_dispatcher(callbacks);
let result: Option<Result<Any>> = dispatcher.dispatch_tuple((AnyView::from(&41_i64),));
let result = result.unwrap()?;
assert_eq!(i64::try_from(result)?, 42);
