Expand description

Convert an input to a reusable Dispatcher.

Args is the complete target argument tuple, Ret its complete result, and M the inferred input-form marker. Target is the actual dispatcher type; Output owns or borrows it and provides BorrowMut<Target>. Owned D and borrowed &mut D inputs both preserve target D; callbacks and tuples use an adapter as their target. This keeps recursive view types tied to the dispatcher.

Inputs may be owned dispatchers, mutable dispatcher borrows, callbacks, or nested tuples mixing these forms. Dispatchers require the exact argument and result signature. Callbacks may accept a leading prefix of one to four arguments; structural callbacks match an FFI value, an object-node borrow, or AnyView; mutation callbacks match a typed MutationView. Callable values and their shared or mutable borrows are stored as supplied, subject to their FnMut implementation. Only an outer None tries the next tuple link; a matched error or inner None stops the chain.

Supply the target argument and result types when calling the conversion directly; the input-form marker remains inferred.

use tvm_ffi::{Any, AnyView, Dispatcher, IntoDispatcher, Result};
let callbacks = (|value: i64| Any::from(value + 1), |_value: AnyView<'_>| Any::new());
let mut dispatcher = IntoDispatcher::<(AnyView<'_>,), Option<Result<Any>>, _>::into_dispatcher(callbacks);
let result: Option<Result<Any>> = dispatcher.dispatch_tuple((AnyView::from(&41_i64),));
let result = result.unwrap()?;
assert_eq!(i64::try_from(result)?, 42);
