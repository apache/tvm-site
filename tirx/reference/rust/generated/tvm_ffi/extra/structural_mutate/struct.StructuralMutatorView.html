Struct StructuralMutatorView 

Source 
pub struct StructuralMutatorView<'a, D, Base = StructuralMutatorObj> { /* private fields */ }
Expand description

The running structural mutation, passed to each handler.

A handler that matches a node decides how its children are rewritten: call default_mutate to rewrite every child through the dispatcher, mutate to rewrite one value, or neither to leave the children as they are. Pass the handler’s own self as dispatch to every method.

See also structural_mutate.

pub fn default_mutate<'input, T>( &mut self, dispatch: &mut D, value: impl Into<MutationView<'input, T>>, ) -> Result<UnchangedOr<Any>>

Rewrite the children of value through the dispatcher, without dispatching value itself again.

Children are found by the type’s registered mutation hook or its reflected fields. A hook uses the mutator only through its arguments, during the call, and must not keep it or call it outside them. The result is unchanged when no child changed; otherwise it is a node with the new children, made in place when value allows it and is uniquely owned.

§Arguments
  • dispatch - The handler’s own self.
  • value - The value whose children to mutate, usually the view the handler received.
§Returns

The rewritten node, or Unchanged.

§Errors

Returns the first error of a child’s handler.
