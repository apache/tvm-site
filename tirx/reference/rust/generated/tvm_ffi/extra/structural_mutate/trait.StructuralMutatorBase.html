Expand description

Native state and default mutation for StructuralMutateEngine. The engine owns allocation, scoped dispatch, identity remaps and results.

§Safety

Self must have a complete initialized C layout with StructuralMutatorObj at offset zero, matching its registered native type and every field hooks access. Native-mutated fields require interior mutability; shared references must not freeze them during recursion. Hooks must preserve the vtable and valid region state.

The base must not implement crate::ObjectCore or otherwise allow callers to retain the runtime. Hooks may access the runtime and borrowed mutation state only synchronously, on the calling thread.

default_mutate_raw returns one owning ABI replacement/Unchanged/Error and recurses only through the installed vtable, preserving the input’s mutation permission. No whole-base mutable reference may span recursion. Failures use the result carrier; panics must not cross native callbacks.
