Struct MutationView 

Source 
pub struct MutationView<'a, T = Any> { /* private fields */ }
Expand description

A borrowed value that a structural mutation may rewrite in place.

Mutation handlers receive a MutationView instead of an owned value, so matching a node does not retain it. Inspect the node through the view, then pass the view to StructuralMutatorView::default_mutate to rewrite its children, or rewrite one field with field. When the node is uniquely owned and the view carries InplaceMode::Allow, its storage is reused instead of copied.

T is the matched type: MutationView<'_, Array<Any>> derefs to the array’s node, and the default MutationView<'_> matches every value. The view is move-only: it cannot be copied or cloned, and consuming it passes on the same permission. A view made from &mut Any may reuse storage; one made with borrowed never does.

See also structural_mutate.

A node borrowed through a copied view cannot survive consumption of the handle:

ⓘ
use tvm_ffi::{StructuralMutatorView, MutationView};
fn invalid<D>(value: MutationView<'_>, dispatch: &mut D, mutator: &mut StructuralMutatorView<'_, D>) {
    let view = value.as_any_view();
    let copy = view;
    let node = copy.downcast_ref::<tvm_ffi::collections::array::ArrayObj>().unwrap();
    mutator.default_mutate(dispatch, value).unwrap();
    println!("{}", node.size);
}

Moving the handle into a nested callback cannot bypass that borrow:

ⓘ
use tvm_ffi::{dispatch, structural_mutate, Any, MutationView, StructuralMutatorView, Result, UnchangedOr};
struct Inner<'a>(Option<MutationView<'a>>);
#[dispatch(mutate, (MutationView<'_>, &mut StructuralMutatorView<'_, Self>), Result<UnchangedOr<Any>>)]
impl<'a> Inner<'a> {
    fn mutate_bool(&mut self, _: bool, mutator: &mut StructuralMutatorView<'_, Self>) -> Result<UnchangedOr<Any>> {
        let pending = self.0.take().unwrap();
        mutator.default_mutate(self, pending)
    }
}
fn invalid(value: MutationView<'_>) {
    let view = value.as_any_view();
    let node = view.downcast_ref::<tvm_ffi::collections::array::ArrayObj>().unwrap();
    structural_mutate(true, Inner(Some(value))).unwrap();
    println!("{}", node.size);
}

A copied inspection view also cannot survive low-level default mutation:

ⓘ
use tvm_ffi::{dispatch, Any, MutationView, StructuralMutatorView, Result, Unchanged, UnchangedOr};
struct Pass;
#[dispatch(mutate, (MutationView<'_>, &mut StructuralMutatorView<'_, Self>), Result<UnchangedOr<Any>>)]
impl Pass {
    fn mutate_any(&mut self, value: MutationView<'_>, mutator: &mut StructuralMutatorView<'_, Self>) -> Result<UnchangedOr<Any>> {
        let view = value.as_any_view();
        let copy = view;
        mutator.default_mutate(self, value).unwrap();
        println!("{}", copy.type_index());
        Ok(Unchanged.into())
    }
}

pub fn downcast_ref<U: DowncastRefFromAny>(&self) -> Option<&U>

Borrow the value as U without changing ownership or permission.

U is anything AnyView::downcast_ref borrows: a managed reference such as Array<i64>, an object type such as ArrayObj, or Any, borrowed in place without a reference-count bump. The check is strict, and the reference borrows this view and cannot survive its consumption.

§Returns

The borrowed value, or None when the value is not a U.

pub fn field<U: MutationField>( &mut self, selector: impl for<'node> FnOnce(&'node T::ContainerType) -> &'node U, ) -> MutationView<'_, U>

Borrow a direct owning field of the node as a view of its own, to rewrite it with StructuralMutatorView::mutate.

The field view exclusively borrows this view. It may reuse the field’s storage only when this view may and the node remains uniquely owned. This does not write the result back into the node: keep the node Unchanged or rebuild it from the result.

§Arguments
  • selector - Returns a reference to one of the node’s own owning fields, an Any or a managed reference.
§Returns

A view of the field.

§Panics

Panics if selector returns a reference outside the node.

let second = mutator.mutate(self, pair.field(|pair| &pair.second))?;

See also structural_mutate.
