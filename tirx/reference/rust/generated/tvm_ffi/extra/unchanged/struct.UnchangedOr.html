Struct UnchangedOr 

Source 
pub struct UnchangedOr<T: ContainerElement = Any> { /* private fields */ }
Expand description

Either a replacement value of type T, or Unchanged to keep the original.

Structural map and mutation callbacks return Result<UnchangedOr<Any>>. It is like Option<T> whose None means “keep what was there”, stored in one FFI value. UnchangedOr<Any> converts with .into() from Unchanged, from a managed reference or scalar, and from a typed UnchangedOr<T>. T is an FFI value type or Any. Converting the wrapper into Any keeps the marker; use value_or_unchanged or into_option when an actual value is needed.

§Examples

use tvm_ffi::UnchangedOr;

fn double_even(value: i64) -> UnchangedOr<i64> {
    if value % 2 == 0 {
        UnchangedOr::changed(value * 2)
    } else {
        UnchangedOr::unchanged()
    }
}

assert_eq!(double_even(4).value_or_unchanged(4), 8);
assert_eq!(double_even(3).value_or_unchanged(3), 3);

pub fn try_cast<U: ContainerElement>(self) -> Result<UnchangedOr<U>>

Check a replacement’s FFI type without cloning it.

An unchanged result is compatible with every replacement type. Erased and narrowing conversions retain the strict type check of Any::downcast_ref. For a known typed conversion, use map(Into::into).

§Returns

The result typed as UnchangedOr<U>.

§Errors

Returns a TypeError if the replacement is not stored as U.

use tvm_ffi::{Any, UnchangedOr};
let erased: UnchangedOr<Any> = 7_i64.into();
assert_eq!(erased.try_cast::<i64>()?.into_option(), Some(7));
