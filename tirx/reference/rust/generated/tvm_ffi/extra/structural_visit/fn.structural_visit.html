Expand description

Visit root with an owned or borrowed Dispatcher.

Handlers receive StructuralVisitorView for explicit recursion and keep state on the dispatcher. Unmatched values use default child traversal. Pass &mut D to keep the dispatcher and inspect its state after the visit. An owned dispatcher is held in the outer call and uses the same borrowed traversal engine.

Callbacks must report failures through Result and must not panic: a panic reaching the non-unwinding native callback boundary aborts the process.

§Arguments

  • root - Value borrowed for traversal, convertible into an AnyView.
  • dispatcher - Owned or mutably borrowed dispatcher implementing IntoDispatcher. Matching handlers control recursion through StructuralVisitorView; unmatched values use default child traversal.

§Examples

Sum integer leaves while default traversal descends into the array:

use tvm_ffi::{
    dispatch, structural_visit, AnyView, Array, Result, StructuralVisitorView,
    VisitInterrupt,
};

struct Sum(i64);
#[dispatch(visit, (AnyView<'_>, &mut StructuralVisitorView<'_, Self>), Result<Option<VisitInterrupt>>)]
impl Sum {
    fn visit_integer(
        &mut self,
        value: i64,
        _: &mut StructuralVisitorView<'_, Self>,
    ) -> Result<Option<VisitInterrupt>> {
        self.0 += value;
        Ok(None)
    }
}

let root = Array::from_vec(vec![1_i64, 2, 3]);
let mut sum = Sum(0);
assert!(structural_visit(&root, &mut sum)?.is_none());
assert_eq!(sum.0, 6);
