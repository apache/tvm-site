Struct StructuralVisitorView 

Source 
pub struct StructuralVisitorView<'a, D, Base = StructuralVisitorObj> { /* private fields */ }
Expand description

The running structural visit, passed to each handler.

A handler that matches a node decides which children are visited: call default_visit to visit every child, visit to visit one value, or neither to skip the children. Pass the handler’s own self as dispatch to every method. A handler returns Ok(None) to continue, or Ok(Some(interrupt)) to stop the whole visit with a VisitInterrupt.

See also structural_visit.

pub fn default_visit<'input, T>( &self, dispatch: &mut D, value: T, ) -> Result<Option<VisitInterrupt>>
where T: Into<AnyView<'input>>,

Visit the children of value through the dispatcher, without dispatching value itself again.

Children are found by the type’s registered visit hook or its reflected fields. The visit stops at the first child that returns an interrupt.

§Arguments
  • dispatch - The handler’s own self.
  • value - The value whose children to visit.
§Returns

None to continue, or the interrupt that stopped the visit.

§Errors

Returns the first error of a child’s handler.
