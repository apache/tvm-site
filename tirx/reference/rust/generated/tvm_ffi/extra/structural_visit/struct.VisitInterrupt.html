Struct VisitInterrupt 

Source 
pub struct VisitInterrupt { /* private fields */ }
Expand description

Interrupt state of a traversal, mirroring C++ ffi.VisitInterrupt.

Entry points and visitor-layer calls return Result<Option<VisitInterrupt>>: Ok(None) means the (sub)graph was visited completely, Ok(Some(..)) means a handler halted the traversal with this interrupt, and Err means it failed.

This is an owning object reference, like Error. Payload reads through interrupt.value borrow the shared VisitInterruptObj; use Self::with instead of a payload-only struct literal. Moving or replacing the payload through this reference is not supported; clone it to retain a separate owner.
