Tensor programs. A Function computes on tensors, variables typed by a TensorType whose Layout maps their indices to memory and threads; tile instructions are dispatched per ThreadScope, and transform and analysis hold the passes and analyses.

Modules§

analysis
Analyses. Read-only queries over functions, statements and expressions: well-formedness and host memory access checks, undefined variables, and linear and clip-bound index patterns.
function
Functions of the dialect. A Function is a BaseFunc whose type is derived from its parameters and return type, with a SeqStmt body; renew_def copies one with fresh variables.
index_map
Index maps. An IndexMap maps the indices of one representation of a tensor to those of another, as a layout transformation does; it maps indices, shapes and tensor data, and inverts when it is bijective.
layout
Layouts. A Layout maps the logical indices of a tensor to coordinates on named Axises, a memory offset and the threads that hold each element; a TileLayout builds the map from strided Iter factors, and a ComposeLayout swizzles the memory coordinate of one.
op
Operators of the dialect. The functions build calls of its operators, such as logaddexp and reinterpret; a CallFFIKernelAttr holds the launch metadata of a call_ffi_kernel call.
op_attr
Operator attributes. The typed keys of the attributes the dialect reads from an operator, set with OpDef::set_attr.
structural
Constraint-aware traversal. A StructuralVisitorWithConstraintContext visits values and a StructuralMutatorWithConstraintContext rewrites them, each keeping the ConstraintContext of the bindings, ranges and guards in scope at the current value.
structural_map_with_constraint_context
Constraint-aware structural mapping. structural_map_with_constraint_context calls a closure on every value with the facts in scope there and replaces the value with what it returns, unless that is Unchanged.
structural_mutate_with_constraint_context
Constraint-aware structural mutation. structural_mutate_with_constraint_context rewrites a value with a dispatcher whose handlers read the facts in scope from the StructuralMutatorWithConstraintContextView they are given.
structural_visit_with_constraint_context
Constraint-aware structural visiting. structural_visit_with_constraint_context visits a value with a dispatcher whose handlers read the facts in scope from the StructuralVisitorWithConstraintContextView they are given.
structural_walk_with_constraint_context
Constraint-aware structural walking. structural_walk_with_constraint_context calls a closure on every value with the facts in scope there, to observe the value, not to rewrite it.
tensor
Tensors. A tensor is a Var whose type is a TensorType, which fixes its shape, element type, memory scope, alignment and Layout; loads and stores subscript the variable, and TensorVar matches one in an operator signature.
thread_scope
Thread scopes. A ThreadScope is one level of a backend’s thread hierarchy, such as cuda.warp; each backend registers its levels, ranked from the widest down.
tile
Tile instructions. instruction holds the attributes their calls carry and their validation, and dispatch the context a lowering dispatches each call in.
transform
Passes of the dialect. transform holds the passes over TIRx functions, and function_pass builds one from a Rust closure.
type
Types of the dialect beyond tensors. A TensorMapType types the tensor-map descriptors that backend memory operations take; tensors are typed by TensorType.
