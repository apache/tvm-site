tvm_tirx::tirx::transform

Module transform 

Source
Expand description

The passes of the dialect. Each function returns a Pass over the TIRx functions of a module; RemoveNoOpConfig and UnrollLoopConfig are the pass context options that configure remove_no_op and unroll_loop.

Structs§

RemoveNoOpConfig
The configuration of remove_no_op, the pass context option tirx.RemoveNoOp: ignore_profiler_call treats profiler calls as no-ops, and a non-zero max_simplification_steps makes the simplifier fail after that many rewrite steps, for debugging.
RemoveNoOpConfigObj
The object behind RemoveNoOpConfig.
UnrollLoopConfig
The configuration of unroll_loop, the pass context option tirx.UnrollLoop.
UnrollLoopConfigObj
The object behind UnrollLoopConfig.
