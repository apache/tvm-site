Expand description

Map every occurrence with the constraint facts active at that position.

Pre-order callbacks run before descending into the replacement’s children; post-order callbacks see the rewritten value after its scope is restored. Facts for later siblings use the resulting bindings and expressions. Unchanged keeps the current value and still descends in pre-order. The root is consumed: moved unique roots may reuse storage, retained roots copy. Errors stop traversal without rolling back completed in-place changes.

Accepts the shared IntoDispatcher forms: owned or borrowed dispatchers, typed callbacks, and nested tuples. Callbacks take a leading prefix of (value, &ConstraintContext, DefRegionKind) and return a replacement, Unchanged, or a Result thereof. Observers must not append to the active context or panic across native callbacks. Clone a context to retain its live handle, or use snapshot() / to_array() for a fixed prefix.
