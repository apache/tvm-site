Layouts: how the indices of a tensor map to memory and to threads.

The objects python/tvm_tirx/tirx/layout.py defines. Layout is the base. A TileLayout maps indices through the Iters of its shard (distinct elements) and replica (copies), each an extent and a stride over an Axis. A ComposeLayout applies an XOR swizzle to the memory coordinate of a tile layout. The methods wrap the native tirx.Layout*, tirx.Axis* and tirx.TileLayout* functions; a Layout method takes a subclass through Layout::from(&x).
