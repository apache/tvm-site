Module layout 

Source
Expand description

Layouts. A Layout maps the logical indices of a tensor to coordinates on named Axises, a memory offset and the threads that hold each element; a TileLayout builds the map from strided Iter factors, and a ComposeLayout swizzles the memory coordinate of one.

Structs§

Axis
A named coordinate a layout maps to: the memory axis m, or a thread axis, such as laneid, that indexes the threads of a scope. Each name is one registered axis, which Axis::get_or_register looks up, registering it on first use.
AxisObj
The object behind Axis.
ComposeLayout
The layout tile_layout with its memory coordinate XOR-swizzled: above the low per_element bits, the group of swizzle_len bits atom_len bits up is XORed into the group below if swizzle_inner, and the lower group into the upper one otherwise.
ComposeLayoutObj
The object behind ComposeLayout.
Iter
One factor of a TileLayout: extent positions, each adding stride to the coordinate on axis.
IterObj
The object behind Iter.
Layout
The base of every layout: a map from the logical indices of a tensor to a coordinate on each of its Axises, such as the memory axis m or a thread axis.
LayoutObj
The object behind Layout.
TileLayout
The layout of strided factors: each Iter of shard spans distinct elements and each of replica their copies, adding its stride per position to the coordinate on its axis, from the origin offset gives on each axis.
