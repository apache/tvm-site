Check the invariants of the layout (tirx.LayoutCheckWellFormed).

pub fn tile( &self, outer: impl Into<TileLayout>, outer_shape: impl IntoIterator<Item = impl IntoExpr<PrimExpr>>, inner_shape: impl IntoIterator<Item = impl IntoExpr<PrimExpr>>, ) -> Result<Layout>

Return this layout, of inner_shape, tiled by outer, of outer_shape (tirx.LayoutTile).

§Errors

Returns an error if outer_shape and inner_shape differ in length, or a layout cannot be grouped by its shape.
