tvm_tirx::tirx::tile::dispatch

Struct DispatchContext 

Source 
pub struct DispatchContext { /* private fields */ }
Expand description

The context a tile instruction call is lowered in: the target, the thread_scope of the call, the kernel’s launch_params, the ranges of the loop variables in scope (var_range_map), the axis views across and within teams (inter, intra) and the scope_kind.

Through it a dispatch requests allocations and statements, and caches objects that later dispatches of the same lowering reuse. A context with alloc_only set is used only to allocate tensors.

§Examples

use tvm_tirx::ir::{Evaluate, IntImm, PrimType, PrimVar, UNKNOWN_LOC};
use tvm_tirx::target::Target;
use tvm_tirx::tirx::tile::DispatchContext;
use tvm_tirx::tirx::ThreadScope;
use tvm_tirx::tvm_ffi::{EnumRef, Map};

let tx = PrimVar::new("tx", PrimType::int(32), UNKNOWN_LOC);
let ctx = DispatchContext::new(
    Target::new("cuda")?,
    ThreadScope::get("cuda.warp")?,
    [("threadIdx.x", tx, 32)],
    Map::new(), false, Map::new(), Map::new(), Map::new(), Map::new(),
    "warp",
)?;

ctx.cache_set("my_ext.zero", &IntImm::int32(0))?;
assert!(ctx.cache_get("my_ext.zero")?.is_some());
ctx.add_init_stmt(Evaluate::new(1, UNKNOWN_LOC), false)?;

Create the context of a dispatch for target at thread_scope (tirx.DispatchContext).

launch_params maps each launch parameter to its variable and extent; inter and intra map each axis to its [extent, offset] across and within teams.

§Errors

Returns an error if the backend of thread_scope is not the target’s kind, or scope_kind is neither empty nor the local name of thread_scope.
