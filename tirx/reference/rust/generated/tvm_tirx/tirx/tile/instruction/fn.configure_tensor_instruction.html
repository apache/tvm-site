Validate the calls of the tile instruction op with validator, after the checks of its operand count, void type and registered attributes (tirx.ConfigureTensorInstruction).

An operator takes a custom validator once; validator reports an invalid call as an error. The operator registry keeps it for the process and calls it from any thread, so it is Send + Sync.
