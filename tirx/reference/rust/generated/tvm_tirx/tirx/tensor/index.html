Tensors. A tensor is a Var whose type is a TensorType, which fixes its shape, element type, memory scope, alignment and Layout; loads and stores subscript the variable, and TensorVar matches one in an operator signature.

Structs§

TensorType
The type of a tensor of shape and element type dtype in the memory scope, with its data pointer aligned to data_alignment bytes and an optional layout from indices to storage.
TensorTypeObj
The object behind TensorType.
TensorVar
A signature descriptor (sig::ArgType) that matches a Var whose type is a TensorType; it is not a type of its own.
