Module structural_visit_with_constraint_context 

Source
Expand description

Structural visiting with the lexical constraint context.

The shared Rust structural engine owns dispatch and recursion. This module supplies its complete native-compatible base and sparse constraint-aware default hooks; ordinary default traversal is reused when a hook is absent. Native semantic hooks create no analyzer and do not snapshot mutable IR reads.

Hook and global-function registration follows the ordinary visitor/binding trust contract: registered hooks must honor the synchronous ABI, may not retain or concurrently use the visitor, and registration must not race with traversal.
