Visit with native binding, range and guard semantics through the shared Rust engine. A matched dispatcher handler owns descent. Unmatched values use the base’s specialized hook or ordinary structural fallback.

use tvm_tirx::tirx::structural_visit_with_constraint_context::{
    structural_visit_with_constraint_context as visit,
    StructuralVisitorWithConstraintContextView,
};
use tvm_tirx::tvm_ffi::{dispatch, AnyView, Result, VisitInterrupt};

#[derive(Default)]
struct Count(usize);
#[dispatch(visit, (AnyView<'_>, &mut StructuralVisitorWithConstraintContextView<'_, Self>), Result<Option<VisitInterrupt>>)]
impl Count {
    fn visit_number(&mut self, _value: &i64, visitor: &mut StructuralVisitorWithConstraintContextView<'_, Self>)
        -> Result<Option<VisitInterrupt>> {
        assert_eq!(visitor.base().constraints().local_size(), 0);
        self.0 += 1;
        Ok(None)
    }
}
let mut count = Count::default();
visit(&7_i64, &mut count)?;
assert_eq!(count.0, 1);

Callbacks must return failures through Result and must not panic: a panic reaching the non-unwinding native callback boundary aborts the process. Hooks and reflected metadata retain the ordinary visitor’s trust obligations.
