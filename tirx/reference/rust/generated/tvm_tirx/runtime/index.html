The runtime objects the IR refers to.

A MemoryScope, such as the scope of a PtrType, is an enum object that python/tvm_tirx/runtime/memory_scope.py defines. The runtime functions the Python package wraps are here too: tensor allocation and views, device attributes and runtime queries.
