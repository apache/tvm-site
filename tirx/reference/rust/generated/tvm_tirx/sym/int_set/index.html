Module int_set 

Source
Expand description

Integer sets. An IntSet, such as the interval IntervalSet, bounds the values an expression takes; deduce_bound solves a condition for a variable, and the estimate_region_* functions bound the region a set of accesses covers.

Structs§

IntSet
The base of every set of integers, one dimension each, that bounds the values an expression takes; Analyzer::int_set computes one.
IntSetObj
The object behind IntSet.
IntervalSet
The interval [min_value, max_value] of integers, whose bounds are symbolic expressions and may be neg_inf or pos_inf.
IntervalSetObj
The object behind IntervalSet.
