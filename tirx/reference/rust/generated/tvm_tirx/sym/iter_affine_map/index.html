Iterator maps: index expressions decomposed into splits of iterators.

The objects python/tvm_tirx/sym/iter_affine_map.py defines. An IterMark is an iterator source with its extent; an IterSplitExpr is (source // lower_factor) % extent * scale; an IterSumExpr is a sum of splits plus base_. An IterMapResult holds the detected indices, the errors and the padding_predicate. The functions of iter_affine_map.py, which detect, simplify, divide and invert iterator maps, are here too.
