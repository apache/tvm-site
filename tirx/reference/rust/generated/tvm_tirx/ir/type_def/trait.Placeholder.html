Expand description

A valid value of a field type, which an object of a type register_type registers holds until reflection sets the field: __ffi_new__ makes an object with one in every field, and a field __ffi_init__ does not take (#[reflect(init_off)]) keeps it. The object of a type you register implements it, from the placeholders of its parent’s object and its fields; this crate implements it for the common field types, and a field type of your own crate implements it too.
