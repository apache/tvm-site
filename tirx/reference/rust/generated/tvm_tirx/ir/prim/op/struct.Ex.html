tvm_tirx::ir::prim::op

Struct Ex

Source 
pub struct Ex(/* private fields */);
Expand description

An expression being built by operators: either the expression, or the first error any step raised. Later steps pass an error through untouched. An Ex is an IntoExpr, so it passes into any function or constructor that takes one, whose ? then reports the error; Ex::expr takes the expression out.

Any expression node converts into an Ex, as it converts into a C++ PrimExpr. The operators +, -, *, &, |, ^, <<, >>, unary - and ! are the C++ ones, typed after C++: an integer literal on either side is MakeConst(other.ty(), v), an f32 a float32 constant, an f64 a float64 one. / and % are not defined: name the division (PrimOps::truncdiv, PrimOps::floordiv, PrimOps::div, …), as C++ requires of % and of / next to a literal (DivAmbiguityError); C++ / between two expressions is div. Comparisons, && and || are PrimOps methods too, because Rust’s comparison traits return bool.
