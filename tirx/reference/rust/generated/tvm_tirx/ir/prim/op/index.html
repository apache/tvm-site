tvm_tirx::ir::prim

Module op 

Source
Expand description

The primitive operators: arithmetic, comparisons, logic, casts and math functions, after C++ src/ir/prim/op.cc.

Unlike the node constructors such as Add::new, these match their operand types and fold constants, as C++ does. Each builds at the unknown location, and its _at variant takes one. Operators such as &x + 1 build an ExprResult, and PrimOps has the operations Rust has no operator for.

Every function returns a TypeError for an operand that is not a primitive expression, and the trigonometric and hyperbolic ones also for an operand that is not a float.

§Examples

use tvm_tirx::ir::prim::op::{add, floordiv, floormod, mul};
use tvm_tirx::ir::{PrimType, PrimVar, Var, UNKNOWN_LOC};
use tvm_tirx::script::script;
use tvm_tirx::tvm_ffi::ObjectRefCore;

let i = PrimVar::new("i", PrimType::int(32), UNKNOWN_LOC);
assert_eq!(script(&floordiv(&i, 16)?)?, "i // 16");
assert_eq!(script(&floormod(&i, 16)?)?, "i % 16");

assert_eq!(script(&mul(4, 16)?)?, "64");
assert!(add(&i, 0)?.same_as(&i));
