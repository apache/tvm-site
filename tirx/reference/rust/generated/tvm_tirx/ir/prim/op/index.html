Module op

Source
Expand description

The primitive operators: arithmetic, comparisons, logic, casts and math functions, written in Rust after src/ir/prim/op.cc, src/ir/prim/math.cc and include/tvm/ir/prim/op.h.

The functions python/tvm_tirx/ir/prim/op.py defines, with the operators that python/tvm_tirx/ir/_prim_expr_overload.py gives expressions (a + b is add). Unlike the node constructors such as Add::new, which take operands of one type and never fold, these match their operand types (BinaryOpMatchTypes), fold constants (TryConstFold) and may return any Expr: a node, a constant or an intrinsic call, with the checks and errors of the C++ functions.

Each function builds at the unknown location, as the C++ default argument does; the _at variant takes a location. An operand is an expression, an expression under construction (an Ex, see below) or a literal, typed as C++ types it: an integer next to an expression is MakeConst(other.ty(), v), an f32 a float32 constant, an f64 a float64 one, and a literal on its own the constant From makes of it (an i32 is an int32):

use tvm_tirx::ir::prim::op::{add, floordiv};
use tvm_tirx::ir::{PrimType, Var, UNKNOWN_LOC};

let x = Var::new("x", PrimType::int(32), UNKNOWN_LOC);
let index = floordiv(&x + 1, 4)?; // C++ `floordiv(x + 1, 4)`
let shifted = add(&x, 1)?;

&x + 1 is the operator syntax of Ex: the C++ operators on an expression, a Var or an Ex, with literals typed the same way. An Ex holds the expression under construction or the first error any step raised; it passes into any function or constructor that takes impl IntoExpr, whose ? then reports that error, and Ex::expr takes the expression out. The operations Rust has no operator for are the PrimOps methods (x.floordiv(4), x.less(y), x.cast(ty)).

Structs§

  • Ex
    An expression being built by operators: either the expression, or the first error any step raised. Later steps pass an error through untouched. An Ex is an IntoExpr, so it passes into any function or constructor that takes one, whose ? then reports the error; Ex::expr takes the expression out.

Enums§

  • ConstValue
    The value of a constant, as C++ MakeConst takes it: an integer or a double.

Traits§

  • Operand
    An operand of an operator: an expression, an expression under construction (Ex) or a literal, which is typed after the expression it meets (C++ TVM_DEFINE_BINOP_CONST_VAL_OVERLOAD and friends): an i32 or i64 is MakeConst(other.ty(), v), an f32 a float32 constant, an f64 a float64 one. A literal that meets no expression is the constant From makes of it.
  • PrimOps
    The C++ PrimExpr operations that are functions rather than Rust operators, as methods of an Ex, an Expr or a Var. Each takes an expression or a literal on the right, typed as for the operators, and leaves self usable; the comparisons are named after the C++ functions (less, equal), since Rust’s eq and lt return a bool.
