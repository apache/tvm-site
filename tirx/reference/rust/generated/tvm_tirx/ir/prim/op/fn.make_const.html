pub fn make_const(
    ty: impl Into<PrimType>,
    value: impl Into<ConstValue>,
) -> Result<Expr>
Expand description

The constant value of type ty: an IntImm of an integer or boolean type, a FloatImm of a floating-point type, and the scalar constant broadcast over the lanes of a vector type (C++ prim::MakeConst(ty, value), which has no global function). An unsigned type takes no negative value. Prefer IntImm::from_dtype or FloatImm::from_dtype when the kind of the type is known.
