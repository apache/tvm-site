Module vector_expr 

Source
Expand description

Vector expressions. A vector is built from scalars by a Ramp (lanes values from base by stride) or a Broadcast (one value repeated), and rearranged by a Shuffle; its lane count is a constant or, for a scalable vector, vscale() * factor.

Ramp
The vector of lanes values base, base + stride, …, such as the indices of a vector load; base and stride are scalar int32, int64, uint32 or uint64.
RampObj
The object behind Ramp.
Shuffle
The vector of the lanes at indices of the concatenated vectors, which share an element type.
