Primitive expressions: scalar arithmetic, comparisons and vector lanes.

Laid out like python/tvm_tirx/ir/prim/: expr holds the scalar expressions, vector_expr the vector ones and op the type-promoting operators. This module holds expr_deep_equal, from prim/__init__.py.

  • pub use op::*;
  • pub use vector_expr::*;

Modules§

  • expr
    Scalar expressions: casts, arithmetic, bitwise and logical operations, comparisons, Select and Let.
  • op
    The primitive operators: arithmetic, comparisons, logic, casts and math functions, written in Rust after src/ir/prim/op.cc, src/ir/prim/math.cc and include/tvm/ir/prim/op.h.
  • vector_expr
    Vector expressions: Ramp, Broadcast and Shuffle.
