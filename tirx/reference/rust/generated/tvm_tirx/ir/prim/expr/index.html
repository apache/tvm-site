Module expr

Expand description

Scalar expressions: casts, arithmetic, bitwise and logical operations, comparisons, Select and Let.

The objects python/tvm_tirx/ir/prim/expr.py defines. A binary operation such as Add holds its operands a and b. Their new is written in Rust after the C++ constructor: it checks the operand types and derives the result type. The type-promoting operators are in super::op.
