Signature descriptors for OpDef::signature.

arg and ty_arg are fixed value and type arguments, var_args and var_ty_args variadic tails, and call_attrs the type of Call.attrs. A node type accepts an instance of it, and the typed expressions such as PrimExpr and PrimVar also check its type; implement ArgType for another check.
