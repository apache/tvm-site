Signature descriptors, for OpDef::signature (C++ sig::arg<T> and friends): the arguments an operator takes, with their documentation and the types a generated validator checks.

arg and ty_arg are the fixed value and type arguments, in order, var_args and var_ty_args a variadic tail of each, and call_attrs the type of Call.attrs. As an argument type, a node type, such as StringImm or Var, accepts an instance of it, as C++ TypeTraits<T>::CheckAnyStrict does, and Expr or Type accepts any. PrimExpr, IntExpr and PrimVar are the C++ view types, which also check the expression’s type, as is TensorVar. Implement ArgType for another check.
