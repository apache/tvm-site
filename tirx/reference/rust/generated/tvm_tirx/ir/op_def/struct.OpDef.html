Struct OpDef

Source 
pub struct OpDef(/* private fields */);
Expand description

C++ OpDef: register a new operator from Rust.

Each step updates the registry at once, as in C++. After a failed step the rest are skipped, and OpDef::op returns the error. The registry does not synchronize registration with readers, so register an operator before building IR with it, as a tvm_ffi::static_init_block! does. An operator and its hooks live for the rest of the process.

use tvm_tirx::ir::op_attr::CALL_EFFECT_KIND;
use tvm_tirx::ir::sig::{self, IntExpr};
use tvm_tirx::ir::{CallEffectKind, CallObj, OpDef, Type};
use tvm_tirx::tvm_ffi::Result;

fn first_arg_type(call: &CallObj) -> Result<Type> {
    Ok(call.args.get(0)?.ty.clone())
}

let op = OpDef::new("my_ext.clamp", "Clamp an index to a bound.")
    .signature((sig::arg::<IntExpr>("index", ""), sig::arg::<IntExpr>("bound", "")))
    .set_infer_type(first_arg_type)
    .set_attr(CALL_EFFECT_KIND, CallEffectKind::Pure)
    .op()?;

pub fn op(self) -> Result<Op>

The completed operator, or the error of the step that failed. Request its APIs in registered destinations through ir.expose_op after its signature and attributes are ready. An absent receiver is a no-op; an installed receiver’s error is returned.

Source

pub fn signature<S: Specs>(self, specs: S) -> Self

C++ OpDef::signature: replace the argument descriptions and the attrs type, and the validator generated from them, which checks a Call’s argument counts, argument types and attrs. specs is a descriptor of sig, or a tuple of them in order, as C++ takes them. A custom validator keeps precedence. Without sig::call_attrs the operator has no attrs type, and Call.attrs is unconstrained.

A custom validator, run by Call::validate, which reports an invalid Call as an error. It replaces the one a signature generated, and a later signature keeps it; a second custom validator is an error. validate is a function or a closure that captures nothing.
