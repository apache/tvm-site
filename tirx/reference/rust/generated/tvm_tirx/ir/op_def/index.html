Operator registration from Rust: C++ OpDef.

OpDef registers an operator with its signature (sig) and attributes (op_attr) in a tvm_ffi::static_init_block!, as C++ does in a TVM_FFI_STATIC_INIT_BLOCK. Its hooks are native functions that C++ calls without packing arguments.
