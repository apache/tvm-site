Module op_def

Source
Expand description

Registering operators from Rust: C++ OpDef, with its signature descriptors (sig) and attribute keys (op_attr), whose chains a tvm_ffi::static_init_block! runs to define operators, as C++ defines them in a TVM_FFI_STATIC_INIT_BLOCK; and the handles that keep operators in statics.

Every hook an operator gets here is native, as the C++ ones are: a Rust function compiled into the C ABI adapter that C++ NativeFunctionView calls through a function pointer, without packing arguments. A signature generates its validator from its argument types, as C++ OpDef::signature does from sig::arg<T>; each signature is its own compiled function.

A tvm_ffi::static_init_block! is gathered at link time, wherever in the program or library it is, and runs when it loads, as a C++ static init block does, so that once Python loads a library built on this crate, by any means, it sees the operators and types the block defines as it sees those of a C++ library. A block that several libraries of a process have, as each links its own copy of a crate they share, runs once.

Modules§

  • op_attr
    The operator attributes of the shared IR (C++ tvm::op_attr). The hooks, FInferType and the region ones, have setters of their own on OpDef.
  • sig
    Signature descriptors, for OpDef::signature (C++ sig::arg<T> and friends): the arguments an operator takes, with their documentation and the types a generated validator checks.

Structs§

  • AttrKey
    C++ ffi::reflection::AttrKey<T>: the name of an operator attribute and the type of its values, which OpDef::set_attr takes. op_attr and tirx::op_attr have the keys C++ declares, and AttrKey::new names another.
  • OpDef
    C++ OpDef: register a new operator from Rust.
  • OpHandle
    A handle to an operator, kept in a static as C++ keeps one in const Op& xxx_op(). The operator is looked up by name once per thread; OpHandle::get returns it and OpHandle::is compares with it. The tvm_ffi::static_init_block!s that define operators run when their program or library loads; where the loader does not run them, the first lookup of an operator that is not registered runs them, with tvm_ffi::run_static_init_blocks.
