Types: primitive, pointer, tuple, function and the special types.

The objects python/tvm_tirx/ir/type.py defines. Type is the base of every type; a dialect extends it, as TensorType does. The constructors are new, written in Rust after the C++ ones; the shared types (MissingType::new, NoneType::new, TensorRegionType::new and PrimType::from_dtype) are the nodes C++ shares, fetched once per thread. The common primitive types are PrimType::int, PrimType::float, PrimType::bool and their siblings, as C++ writes PrimType::Int(32).
