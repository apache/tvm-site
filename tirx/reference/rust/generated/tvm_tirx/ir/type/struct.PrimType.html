Struct PrimType 

Source 
pub struct PrimType { /* private fields */ }
Expand description

A primitive type: a scalar or a vector of a DLPack data type dtype, or void.

It types the operands of arithmetic. PrimType::int, PrimType::float and their siblings give the common scalars, with_lanes and with_scalable_lanes the vectors.

§Examples

use tvm_tirx::ir::PrimType;
use tvm_tirx::script::script;

let half4 = PrimType::float(16).with_lanes(4)?;
assert_eq!(half4.lanes(), Some(4));
assert_eq!(script(&half4)?, "T.float16x4");
