Struct TensorLoad 

Source 
pub struct TensorLoad { /* private fields */ }
Expand description

The element or vector of source at indices: a load from a tensor, or from any expression whose type supports it.

The type of source interprets the indices, in dimension order, and infers the PrimType of the load.
