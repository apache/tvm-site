Expand description

A value that converts into an expression, possibly failing: anything that converts into an Expr, or an ExprResult under construction.

A function that takes impl IntoExpr returns the first error of an ExprResult operand, and a TypeError for an operand that is not a PrimExpr where it takes one.

§Examples

use tvm_tirx::ir::prim::Add;
use tvm_tirx::ir::{PrimType, Var, UNKNOWN_LOC};
use tvm_tirx::script::script;

let x = Var::new("x", PrimType::int(32), UNKNOWN_LOC);
let sum = Add::new(&x + 1, 2, UNKNOWN_LOC)?;
assert_eq!(script(&sum)?, "x + 1 + 2");

let f = Var::new("f", PrimType::float(32), UNKNOWN_LOC);
assert!(Add::new(&f << 1, 2, UNKNOWN_LOC).is_err());
