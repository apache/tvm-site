Expand description

A value that converts into an expression, possibly failing: anything that converts into an Expr, or an ExprResult under construction.

A function that takes impl IntoExpr returns the first error of an ExprResult operand, and a TypeError for an operand that is not a PrimExpr where it takes one.

§Examples

use tvm_tirx::ir::prim::Add;
use tvm_tirx::ir::{PrimType, Var, UNKNOWN_LOC};
use tvm_tirx::script::script;

let x = Var::new("x", PrimType::int(32), UNKNOWN_LOC);
let sum = Add::new(&x + 1, 2, UNKNOWN_LOC)?;
assert_eq!(script(&sum)?, "x + 1 + 2");

let f = Var::new("f", PrimType::float(32), UNKNOWN_LOC);
assert!(Add::new(&f << 1, 2, UNKNOWN_LOC).is_err());

Required Associated Types§

Source

type Output: Borrow<Expr> + Into<Expr>

The expression: an owned Expr for an owned value or a literal, or a borrowed &Expr for a reference, which converts without a reference-count change.

A function that only reads the expression borrows it with .borrow(); one that keeps it takes ownership with .into(), which clones only a borrowed expression.

Provided Methods§

fn into_owned_expr(self) -> Result<Expr>
where Self: Sized,

Convert into an owned expression, as Cow::into_owned does: an owned value moves, and only a borrowed expression is cloned.
