Module stmt 

Source
Expand description

Statements: bindings, assertions, loops, conditionals, tensor stores and sequences.

The objects python/tvm_tirx/ir/stmt.py defines. Stmt is the base of every statement and carries its location. The constructors are new (checked for While), written in Rust after the C++ ones with their checks; a body given as one statement is wrapped in a SeqStmt, as C++ converts it.
