impl Sequential

Source

pub fn new( passes: impl IntoIterator<Item = impl Into<Pass>>, pass_info: impl Into<PassInfo>, ) -> Self

Create a pass with the information pass_info that runs passes in order (C++ Sequential(passes, pass_info)).

It skips the passes the current pass context disables, and those whose level exceeds the context’s opt_level unless the context requires them. C++ Sequential(passes, name) is Sequential::new(passes, PassInfo::new(0, name)).
