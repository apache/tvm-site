Module dtype

Source
Expand description

The DLPack data types by their fields, for a caller that knows the type it wants: dtype::int(32) where C++ writes DataType::Int(32), instead of parsing "int32" with DLDataType::try_from_str. These are plain values with no native call, so they can be constants and can be compared; PrimType::int and its siblings give the IR type of each.

  • with_lanes
    The vector of lanes elements of the scalar dtype (C++ DataType::with_lanes): with_lanes(float(16), 4) is float16x4. lanes is stored as the DLPack lane field: a fixed-length vector has fewer than 32768 lanes, and the values from 32768 up encode the scalable vectors of PrimType::with_scalable_lanes, which PrimType::with_lanes rejects.
