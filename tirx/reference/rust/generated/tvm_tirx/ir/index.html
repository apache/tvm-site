Module ir

Expand description

The shared IR: expressions, statements, types, functions, modules and operators.

Laid out like python/tvm_tirx/ir/. Expr, Stmt and Type are the bases of the three node hierarchies, and IRModule holds the functions of a program. prim holds the primitive expressions and transform the pass infrastructure.

Modules§

  • attrs
    Attributes attached to calls, functions and modules.
  • base
    Functions of the global registry referred to by name.
  • dtype
    The DLPack data types by their fields, for a caller that knows the type it wants: dtype::int(32) where C++ writes DataType::Int(32), instead of parsing "int32" with DLDataType::try_from_str. These are plain values with no native call, so they can be constants and can be compared; PrimType::int and its siblings give the IR type of each.
  • expr
    Expressions: variables, constants, calls, tuples and tensor accesses.
  • function
    The base of every function.
  • global_info
    Module-level information that is not a function.
  • location
    Source locations of IR nodes, for diagnostics.
  • module
    The module: the unit of compilation.
  • op
    Operators: the registry entry Op, its ArgumentInfo, and its attribute columns.
  • op_def
    Registering operators from Rust: C++ OpDef, with its signature descriptors (sig) and attribute keys (op_attr), whose chains a tvm_ffi::static_init_block! runs to define operators, as C++ defines them in a TVM_FFI_STATIC_INIT_BLOCK; and the handles that keep operators in statics.
  • prim
    Primitive expressions: scalar arithmetic, comparisons and vector lanes.
  • stmt
    Statements: bindings, assertions, loops, conditionals, tensor stores and sequences.
  • transform
    The pass infrastructure: passes, pass contexts and instrumentation.
  • type
    Types: primitive, pointer, tuple, function and the special types.
  • type_def
    Registering IR types from Rust: register_type, which a tvm_ffi::static_init_block! calls for an rs_class type, as C++ registers a type with refl::ObjectDef in a TVM_FFI_STATIC_INIT_BLOCK.
  • unique_name_supply
    A supply of unique names, for building and rewriting IR.
