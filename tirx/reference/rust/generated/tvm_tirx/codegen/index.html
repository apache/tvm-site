Code generation. build_module compiles an IRModule into a runtime Module with the code generator of the target’s kind, and llvm queries the LLVM backend.

Modules§

llvm
The LLVM backend. Queries of LLVM intrinsics, the host CPU and the CPUs and features of LLVM targets, which libtvm_tirx_llvm_backend registers when it is loaded. Target-dependent queries require an explicit target.
