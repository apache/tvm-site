The LLVM backend: intrinsics, the host system and the CPUs and features of LLVM targets.

The functions of python/tvm_tirx/codegen/llvm.py, and the host queries python/tvm_tirx/target/detect_target.py makes. A query that takes an optional target falls back to the current one, and answers nothing for a target that is not llvm.
