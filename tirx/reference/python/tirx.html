Additional Structural Visit and Mutate APIs#

Traverse and transform TIRx with the facts available at each use.

Callbacks receive a tvm_tirx.sym.ConstraintContext: iterate it to read facts, or use list(context) to retain an independent list. Bind/Assert add facts for later statements; If/While/lazy calls add guards, For/thread launch add ranges, and Let adds a body binding. Mutation uses the transformed values. Call and RegionStmt use registered operator hooks; other calls follow ordinary descent, and other regions isolate their body facts.

Callbacks control descent. Normal exits and interrupts restore outer facts; errors propagate without restoration, so discard the traversal after failure. The C++ structural visitor and mutator docs describe the full collection rules.

StructuralVisitorWithConstraintContext()

Visits values using their structural visit behavior while maintaining the constraint context relevant to each callback.

Mutates values using their structural mutation behavior while maintaining the constraint context relevant to each callback.
