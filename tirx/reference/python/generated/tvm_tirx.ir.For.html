class tvm_tirx.ir.For(var, begin, end, step, kind, body, annotations=None, loc=UNKNOWN_LOC)#

Bases: Stmt

Iterate from begin while below end, incrementing by step.

Parameters:

  • var (Var) – The loop variable.

  • begin (Expr) – The beginning value.

  • end (Expr) – The exclusive end of the loop.

  • step (Expr) – The required loop step, including a typed one for unit stride.

  • kind (ForKind) – Sequential, parallel, vectorized, or unrolled execution semantics.

  • body (Stmt | Sequence[Stmt]) – The body statement.

  • annotations (Optional[Mapping[str, tvm_ffi.Object]]) – Additional loop annotations interpreted by the consuming dialect.

  • loc (Location, optional) – The location of the stmt in the source code.

ForKind#

class tvm_tirx.ir.ForKind(value)#

Bases: IntEnum

Execution semantics of a For loop.

DEFAULT executes iterations sequentially; PARALLEL permits parallel execution. VECTORIZED requests a vectorized body and UNROLLED requests unrolling. Transformations must preserve the selected execution semantics.

DEFAULT = 0#
PARALLEL = 1#
VECTORIZED = 2#
UNROLLED = 3#
