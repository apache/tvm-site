tvm_tirx.sym.Analyzer#

class tvm_tirx.sym.Analyzer#

Bases: Object

Integer arithmetic analyzer

This is a stateful analyzer class that can be used to perform various symbolic integer analysis. The same analyzer instance can be passed to FFI APIs to share accumulated facts across calls.

property is_z3_enabled: bool#

Whether this build includes the Z3 backend (USE_Z3=ON).

The Z3-specific methods (get_smtlib2(), get_z3_stats(), set_z3_timeout_ms(), set_z3_rlimit()) only work when this is True.

clone()#

Return a deep copy of this analyzer with independent state.

The returned analyzer carries the same accumulated facts (variable bounds, modular sets, bindings, integer-set domains, literal constraints and transitive comparisons) as this one, but owns its own state: synchronizing or simplifying either analyzer afterwards does not affect the other. Unlike copying the handle, this is a true deep copy.

Returns:

result (Analyzer) – A new analyzer holding an independent copy of the facts.

Return type:

Analyzer

set_maximum_rewrite_steps(maximum)#

Set the maximum allowed number of rewrite-simplify steps.

When a positive limit is set, the simplifier raises an exception once it exceeds that number of rewrite steps. This is useful for guarding against performance regressions in tests.

Parameters:

maximum (int) – The maximum number of rewrite steps, or a non-positive value to allow an unlimited number of steps.

Return type:

None

sync_constraint_context(context)#

Synchronize this analyzer with the premises visible in context.

The analyzer captures the current context position. Later appends become visible only after another synchronization. Switching to a parent, sibling, or empty context removes facts no longer present there. Repeating this call for an unchanged context is inexpensive.

Parameters:

context (ConstraintContext) – Binding, range, and predicate premises for subsequent queries. Captured premises and their referenced expressions must not be modified through aliases.

Return type:

None
