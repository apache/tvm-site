Rust API
========

The ``tvm-tirx`` crate in ``rust/`` binds the TIRx compiler objects over TVM FFI.
Its modules follow the Python package: ``tvm_tirx::ir`` is :doc:`tvm_tirx.ir
<../python/ir>`, ``tvm_tirx::tirx`` is :doc:`tvm_tirx.tirx <../python/tirx>`, and so
on. Operators can also be defined from Rust with its ``register_ops!`` macro, as
:doc:`tvm_tirx.backend.rust <../python/backend.rust>` loads them.

The reference is generated by ``cargo doc`` when the documentation is built with
``BUILD_RUST_DOCS=1`` (see :doc:`../../dev/doc_build`).

Crates
------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Crate
     - Description
   * - 📦 `tvm-tirx <generated/tvm_tirx/index.html>`_
     - The IR, TIRx, symbolic analysis, target, backend, runtime, codegen and script
       bindings, the Rust IR constructors and operators, and ``register_ops!``.
   * - 📦 `tvm-ffi <generated/tvm_ffi/index.html>`_
     - The TVM FFI objects, functions and containers the bindings are built on,
       re-exported as ``tvm_tirx::tvm_ffi``.
